# KPN · 단말기 메뉴얼
종류: 메뉴얼
VAN: KPN
장비: 단말기

## 토스 터미널 › 초기 화면
- 메뉴 열기 = 왼쪽 위 ☰ 버튼 터치
- 금액 입력 = 숫자패드 1~9, 0, 00, 000

## 토스 터미널 › 결제 방법
- 시작 = 숫자패드에서 금액 입력 > [결제] 버튼 > 결제수단 선택
- 결제수단 선택 1페이지 = 카드 | 현금 | QR·바코드 | 페이스페이
- 결제수단 선택 2페이지 = 카드번호 입력(키인승인 설정 시) ※ 오른쪽 화살표를 눌러야 2페이지가 표시됨
- QR·바코드 결제 = 결제수단 선택 > QR·바코드
- 페이스페이 결제 = 결제수단 선택 > 페이스페이

## 토스 터미널 › 결제 방법 › 카드
- 카드 선택 후 = 삼성페이 | 애플페이·NFC

## 토스 터미널 › 결제 방법 › 현금
- 현금영수증 발급 = 현금 > 현금영수증 발급 > 현금영수증 번호 입력
- 자진발급 = 현금 > 자진발급
- 건너뛰기 = 현금 > 건너뛰기

## 토스 터미널 › 결제 방법 › 카드번호 입력(키인)
- 진입 = 결제수단 선택 > 오른쪽 화살표(2페이지) > 카드번호 입력
- 입력 화면 = 카드 번호를 입력해주세요 > 카드번호 입력 > 유효기간 입력 ※ 키인승인을 설정한 경우에만 표시됨 (설정 › 결제 정보 › 카드번호로 결제 사용하기)

## 토스 터미널 › 결제내역/취소
- 직전 결제 보기 = ☰ 메뉴 > 결제내역/취소 옆 [직전 결제 보기] 버튼
- 직전 결제에서 할 수 있는 일 = 영수증출력 | 결제취소
- 다른 날짜 결제 찾기 = ☰ 메뉴 > 결제내역/취소 > 상단 날짜에서 날짜 선택(달력) > 결제내역 선택 ※ 날짜 양옆 ◀ ▶ 로 하루씩 이동 가능
- 선택한 결제에서 할 수 있는 일 = 영수증출력 | 결제취소
- 수동취소 = 결제내역 화면 오른쪽 위 [수동취소] 버튼
- 목록 표시 = 취소된 건은 취소선과 '취소'로 표시됨

## 토스 터미널 › 매출 리포트

- 날짜 이동 = 상단 ◀ ▶ 로 이동
- 기간 단위 변경 = 오른쪽 위 [일간] 버튼 터치 > 일간/주간/월간
- 상단 탭 = 매출요약 | 결제수단별 | 카드사별 | 카테고리별 | 메뉴별
- 하단 [결제내역 보기] = 화면 아래 [결제내역 보기] > 날짜 선택 > 결제내역 선택 > 영수증출력 또는 결제취소
