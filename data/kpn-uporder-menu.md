# KPN · UP오더(아임유) 연동 및 설치 매뉴얼
종류: 메뉴얼
VAN: KPN
장비: 테이블오더
모델: UP오더(아임유)

## UP오더 연동 개요 › 전체 작업 순서
- 사전 준비 1단계 = KPN MMS 및 FirstPOS ASP 계정, 아임유 UP솔루션 USMS 계정을 준비
- 사전 준비 2단계 = FirstPOS 상품 필수 설정과 터치키 등록을 확인
- 사전 준비 3단계 = FirstPOS ASP 대리점관리에서 USMS 사용자 계정을 등록
- 사전 준비 4단계 = KPN MMS의 매장마스터에서 아임유 UP오더 연동을 설정
- 사전 준비 5단계 = USMS 서비스조회에서 가맹점에 UP오더 장비를 추가
- 사전 준비 6단계 = 아임유 ASP의 토핑설정2에서 사이드메뉴를 구성
- 설치 1단계 = UP오더 ASP에 메인 POS IP, 메뉴판, 결제모드, Wi-Fi 정보를 설정
- 설치 2단계 = FirstPOS에서 설치용 QR을 출력하고 태블릿에 앱·Wi-Fi·로그인 정보를 등록
- 설치 3단계 = 태블릿에서 장비와 테이블을 연결
- 설치 4단계 = 선불형 매장만 결제 리더기와 결제모듈을 설정
- 설치 5단계 = 태블릿에서 메뉴 노출과 주문 접수를 테스트

## 계정 및 접속 › 필요한 계정
- KPN MMS = 가맹점 정보 및 FirstPOS 연동 설정에 사용
- FirstPOS ASP = 상품·터치키 및 대리점 설정에 사용
- 아임유 USMS = UP오더 업체·매장·장비 등록에 사용
- KPN MMS 접속 주소 = https://eis.kpn.co.kr/
- FirstPOS ASP 접속 주소 = https://asp.firstpos.co.kr/
- 아임유 USMS 접속 주소 = https://usms.upsolution.co.kr/
- 아임유 ASP 접속 주소 = https://asp.upsolution.co.kr/
- 계정 준비 = UP오더 태블릿 연동에는 UP솔루션 계정과 MMS 계정이 필요 ※ 각 계정의 로그인 정보는 별도 확인

## FirstPOS 상품 설정 › UP오더 연동 필수 상품 정보
- 상품 동기화 시점 = MMS에서 UP오더 사용설정을 저장하면 기존 가맹점 원장 데이터가 자동 생성되고 상품정보가 동기화됨
- 신규 상품 동기화 = 신규 상품 등록 시 UP오더와 실시간 동기화
- 동기화 항목 = 상품명 | 판매가 | 과세 여부 | 상품 설명 | 상품 이미지 | 키오스크 상품 여부 | 사이드 사용 여부
- 키오스크 상품 여부 = Yes로 설정 ※ UP오더 사용을 위한 필수 설정
- 사이드 사용 여부 = Yes로 설정 ※ 사이드 메뉴 구성 시 필수
- 사이드 사용 여부 Yes = UP오더에서 해당 상품이 메뉴로 등록됨
- 사이드 사용 여부 No = UP오더에서 해당 상품이 아이템으로 등록됨
- 상품 이미지 동기화 = FirstPOS ASP에서 상품 이미지를 등록하면 실시간 동기화

## FirstPOS 상품 설정 › 터치키 등록 및 태블릿 노출
- 터치키 등록 경로 = FirstPOS ASP에서 해당 상품의 키오스크 터치키를 등록
- 태블릿 노출 조건 = ASP에서 키오스크 터치키를 등록해야 UP오더 태블릿에 상품이 노출됨
- 터치키 미등록 상태 = UP오더 ASP에는 상품이 보여도 태블릿에는 노출되지 않을 수 있음 ※ 사이드 메뉴로는 사용 가능
- 화면 정렬 기준 = 분류 코드는 코드 순서에 따라 왼쪽부터 표시
- 상품 정렬 기준 = 상품 코드는 코드 순서에 따라 좌측 상단부터 표시

## FirstPOS ASP › USMS 사용자 계정 등록
- 메뉴 경로 = 시스템관리 > POS버전관리 > 대리점관리
- 계정 등록 위치 = 대리점관리 화면 하단의 아임유 USMS 사용자 계정 정보 영역
- 등록 방법 = USMS 사용자 아이디와 비밀번호를 입력한 뒤 저장
- 계정 확인 범위 = 등록한 계정과 비밀번호는 본인만 확인 가능
- 총판 계정 확인 범위 = 총판은 자대리점 아이디까지만 확인 가능

## KPN MMS › 가맹점 UP오더 연동 설정
- 메뉴 경로 = 가맹점정보 > FirstPOS Admin
- 매장마스터 진입 = MMS 원장에서 해당 가맹점의 ADMIN 버튼을 클릭
- 연동 설정 = 매장마스터에서 아임유 UP오더 연동 여부를 '연동'으로 변경하고 저장
- 저장 시 처리 = 저장과 동시에 아임유 가맹점 원장이 자동 생성되고 메뉴 데이터가 동기화됨
- 설정 조건 = MMS 매장 상태가 '오픈'이어야 연동 설정 가능
- 화면 이동 = MMS 화면의 ASP 이동 버튼으로 ASP에 이동 가능

## USMS › 로그인 및 서비스조회 진입
- USMS 접속 = https://usms.upsolution.co.kr/ 접속
- 로그인 = UP솔루션(IMU)에서 발급받은 계정정보로 로그인
- 서비스조회 경로 = 로그인 후 좌측 하단의 서비스조회 버튼 클릭
- 가맹점 확인 = 현재 대리점 정보와 연동된 가맹점 목록 확인
- 매장 상세정보 = 가맹점 목록 왼쪽의 펼침 화살표를 클릭하면 하단에 매장정보 표시
- 장비 설정 진입 = 장비를 추가할 매장의 설정 버튼 클릭
- 업체와 매장 구분 = 회사는 프랜차이즈, 매장은 하위 가맹점을 의미
- 단독 매장 구분 = 단독 매장은 회사명과 매장명이 동일하게 설정됨

## USMS › UP오더 장비 일괄 생성
- 메뉴 경로 = 서비스조회 > 해당 매장 > 설정 > 안드로이드 설정
- 장비 생성 진입 = 안드로이드 설정을 클릭한 뒤 UP오더 일괄생성 버튼 클릭
- 테이블 수량 설정 = 실제 설치할 테이블오더 대수만큼 테이블 번호를 설정
- 포스명칭 앞 문자 = 테이블 번호 앞에 붙일 이름을 입력
- 명칭 예시 = 앞 문자에 '테이블오더'를 입력하면 테이블오더1, 테이블오더2, 테이블오더3 순서로 생성
- 포스 타입 = Android로 고정
- 생성 확인 = 저장 후 장비 목록에 추가된 UP오더 장비가 표시되는지 확인
- 라이선스 차감 = UP오더 장비 1대 추가 시 대리점에 부여된 라이선스 1개 소모
- 라이선스 부족 = 보유 라이선스를 모두 사용하면 추가 장비 생성 불가 ※ 추가 전 잔여 라이선스 확인

## 아임유 ASP › 사이드 메뉴 설정 화면 진입
- ASP 접속 방법 1 = USMS > 서비스조회에서 해당 회사정보의 Login 버튼을 클릭
- ASP 접속 방법 2 = https://asp.upsolution.co.kr/ 에 직접 접속
- 메뉴 경로 = 마스터관리 > 메뉴관리 > 토핑설정2
- 화면 진입 = 마스터관리 클릭 > 메뉴관리 탭 진입 > 토핑설정2 클릭
- 토핑설정2 사용 권장 = 기존 토핑설정은 FirstPOS와 구성 방식이 다르므로 토핑설정2 사용 권장
- 토핑설정2 미표시 = USMS > 서비스조회 > 웹메뉴 관리에서 토핑설정2 메뉴 노출을 활성화 ※ 아래 '토핑설정2 메뉴가 보이지 않을 때' 참고
- 구조 차이 = FirstPOS의 그룹은 UP오더에서 템플릿, FirstPOS의 분류는 그룹, FirstPOS의 상품은 상품에 해당

## 아임유 ASP › 토핑설정2 › 선택 방식별 그룹 설정
- 단일 선택 = 그룹 최소 0 / 최대 1
- 멀티 선택 = 그룹 최소 0 / 최대 N
- 단일 선택 필수 = 그룹 최소 1 / 최대 1
- 멀티 선택 필수 = 그룹 최소 N / 최대 N
- 단일 선택 자동 = 그룹 최소 0 / 최대 1, 아이템의 자동선택을 Y로 설정
- 적용 상품 지정 = 토핑설정 화면에서 해당 토핑을 적용할 상품을 지정
- 템플릿 일괄 적용 = 토핑 템플릿을 이용해 여러 메뉴에 토핑 구성을 일괄 적용 가능

## USMS › 토핑설정2 메뉴가 보이지 않을 때
- 메뉴 경로 = USMS > 서비스조회 > 웹메뉴 관리
- 웹메뉴 관리 진입 = 해당 항목의 설정 버튼 클릭
- 메뉴 검색 = 검색란에 '토핑' 입력
- 메뉴 활성화 = 검색 결과에서 토핑설정2 항목 체크
- 저장 = 저장 버튼을 누른 뒤 페이지 닫기

## UP오더 ASP › 메인 POS 및 네트워크 설정 화면 진입
- 메뉴 경로 = USMS > 서비스조회 > ASP Login > 스마트 오더 > 설정 > UP오더 설정
- 화면 진입 1단계 = USMS 서비스조회에서 ASP Login으로 해당 매장의 ASP에 접속
- 화면 진입 2단계 = 스마트 오더 탭 클릭
- 화면 진입 3단계 = 설정 탭으로 이동한 뒤 UP오더 설정 버튼 클릭

## UP오더 ASP › UP오더 설정 › 메인 POS 및 Wi-Fi
- 메인 POS IP = 매장 메인 POS의 IP 주소 입력
- 메뉴판 설정 = UP오더 선택
- 결제모드 사용 안함 = 주문형 매장
- 결제모드 사용 = 선불형 매장
- 선불형 추가 설정 = 결제모드를 사용하는 경우 주문전용 옵션도 사용안함으로 설정
- Wi-Fi 정보 = 태블릿이 연결할 Wi-Fi 네트워크 정보를 입력하고 저장
- QR 로그인 조건 = 메뉴판 설정이 UP오더로 되어 있어야 QR 로그인 가능
- 설정정보 적용 = 태블릿에서 QR 로그인할 때 이 화면에 저장된 설정정보를 불러옴
- 숨겨진 Wi-Fi = 숨겨진 Wi-Fi 네트워크는 이 화면에서 설정할 수 없음

## FirstPOS › UP오더 › 설치 QR 출력
- 메뉴 경로 = FirstPOS 판매관리 > UP오더
- UP오더 화면 진입 = 메인 POS의 판매관리 화면에서 UP오더 버튼 클릭
- QR 출력 = UP오더 화면 우측 하단의 QR인쇄 버튼 클릭
- QR 종류 = UP오더 앱 설치 QR | Wi-Fi 설정 QR | UP오더 로그인 QR

## 태블릿 › UP오더 앱 및 QR 설정
- 앱 설치 = 태블릿 카메라로 UP오더 앱 설치 QR을 스캔 ※ 이미 앱이 설치된 태블릿을 출고받은 경우 생략 가능
- Wi-Fi 등록 = Wi-Fi 설정 QR을 스캔하여 네트워크 정보 저장
- 로그인 정보 등록 = UP오더 로그인 QR을 스캔하여 로그인 정보 저장
- QR 설정 순서 = 앱 실행 및 설치 > Wi-Fi 설정 > Wi-Fi QR 스캔 > 로그인 화면 > 로그인 QR 스캔 > 환경설정 화면 진입
- Wi-Fi 정보 수정 주의 = QR 인쇄 화면에서 Wi-Fi ID 또는 비밀번호를 수정해도 ASP에 저장된 정보는 변경되지 않음

## 태블릿 › UP오더 환경설정 › 장비 및 테이블 연결
- 메뉴 경로 = UP오더 태블릿 > 환경설정
- 장비 선택 = 기존에 IMU USMS에서 등록한 장비 선택
- 테이블 연결 = 선택한 장비에 맵핑할 테이블 번호 선택
- 층별 테이블명 주의 = UP오더에서는 테이블명만 표시되므로 여러 층에서 테이블 번호가 중복되면 혼동될 수 있음
- 권장 설정 = 2개 이상의 층을 사용하는 매장은 FirstPOS의 테이블명을 층마다 다르게 설정

## 태블릿 › 선불형 결제 환경설정 › 결제모듈 진입
- 적용 대상 = 선불형 매장에만 적용 ※ 주문형 매장은 생략
- 관리자 메뉴 진입 = UP오더 아이콘 클릭
- 관리자 비밀번호 = 현재 시각의 시 2자리와 분 2자리를 이어 붙인 4자리 ※ 예: 18시 20분이면 1820
- 결제모듈 진입 = 결제모듈 아이콘 클릭
- 결제 프로그램 설치 = Fin pay Vcat이 설치되지 않은 경우 설치 화면으로 전환됨

## 태블릿 › 선불형 결제 환경설정 › 리더기 등록
- 메뉴 경로 = 결제모듈 > 장치설정
- 장치 추가 = 장치설정 버튼 클릭 > 화면 좌측 하단의 + 버튼 클릭
- 리더기 선택 = 리더기 버튼 클릭
- 리더기 검색 = 리더기를 태블릿에 연결한 뒤 찾기 버튼 클릭
- 설정 완료 확인 = 리더기 설정 완료 후 무결성 검사 진행
- 초기 화면 복귀 = 뒤로가기 버튼을 눌러 초기 설정 단계로 복귀

## 태블릿 › 선불형 결제 환경설정 › 포스 키 다운로드
- 메뉴 경로 = 결제모듈 설정 화면 > 포스다운로드
- 다운로드 진입 = 포스다운로드 버튼 클릭
- 인증 정보 입력 = 사업자번호와 제품번호 입력
- 키 다운로드 = 인증 버튼을 눌러 키 다운로드 진행
- 제품번호 관리 권장 = 태블릿과 제품번호를 1:1로 맵핑하는 방식 권장
- 제품번호 공용 사용 주의 = 하나의 제품번호를 여러 태블릿에서 공용으로 사용할 수는 있으나, 오류 발생 시 로그 분석에 시간이 더 걸릴 수 있음

## UP오더 태블릿 › 설치 완료 및 주문 테스트

- 프랜차이즈 매장 재연동(관리 대리점 변경, 업체 존재) = 기존 연동 업체를 사용하고 매장을 생성하며 아임유 UP오더 초기화 필요
