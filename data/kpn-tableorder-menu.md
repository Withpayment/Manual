# KPN · 테이블오더 메뉴얼
종류: 메뉴얼
VAN: KPN
장비: 테이블오더

## 업오더(아임유) › 관리자 메뉴 진입
- 전원 버튼 길게 누르기 = 전원 버튼을 길게 눌러서 관리자 메뉴 진입 ※ 관리자 비밀번호·제품키는 별도 안내

## 업오더(아임유) › 접속·문의
- USMS 접속 주소 = usms.upsolution.co.kr ※ 로그인 정보는 별도 안내
- 아임유 기술상담 = 1566-4534

## 업오더(아임유) › 사이드 메뉴 생성
- 1단계 (퍼스트포스 ASP) = 퍼스트포스 ASP에서 사이드 메뉴 생성 (분류만 생성)
- 2단계 (아임유 ASP) = 아임유 ASP의 토핑설정 2에서 그룹 설정 ※ 선택 방식별 값은 아래 참조

## 업오더(아임유) › 사이드 메뉴 생성 › 선택 방식별 그룹 설정
- 단일선택 = 그룹 최소 0 / 최대 1
- 멀티선택 = 그룹 최소 0 / 최대 N
- 단일선택 필수 = 그룹 최소 1 / 최대 1
- 멀티선택 필수 = 그룹 최소 N / 최대 N
- 단일선택 자동 = 그룹 최소 0 / 최대 1, 아이템의 '자동선택'을 Y로

## 업오더(아임유) › 대기 화면 변경
- 대기 화면 변경 = 아임유 ASP > 스마트오더 > UP오더 이미지설정

## 업오더(아임유) › 대분류 세로 템플릿
- 세로 템플릿 설정 = 스마트오더 > 설정 > UP오더 설정 > 템플릿

## 업오더(아임유) › 메뉴 추천 표시
- 추천 배지 표시 = 마스터관리 > 메뉴관리 > 메뉴판관리 > 편집 > 대분류 선택 > 메뉴 왼쪽 위의 연필 클릭 > 배지

## 업오더(아임유) › 2인 메뉴 주문 설정
- 1. 웹메뉴관리 설정 = 통합관리지원시스템 > 서비스조회 > 웹메뉴관리 설정 > 메뉴관리 > '매장별 품목설정(확장)' 체크
- 2. 확장설정 = 스마트 오더 > 설정 > 업오더 설정 > 확장설정 > 최소주문수량 > 첫주문 또는 항상사용
- 3. 메뉴별 수량 = 마스터 관리 > 메뉴관리 > 매장별 품목설정(확장) > 메뉴 선택 후 최소주문 수량 입력

## 업오더(아임유) › 외국어 번역
- 다국어 명칭 번역 = 마스터 관리 > 메뉴관리 > 다국어 명칭변경 > 구분(품목/품목노트 등) 선택 > 조회 > 번역 > 저장 ※ 퍼스트포스 ASP>상품등록>사이드메뉴사용여부
