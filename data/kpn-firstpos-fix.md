# KPN 문제 해결 (FirstPos)
종류: 문제해결
VAN: KPN
모델: FirstPos

## 키오스크 연결 안 됨 - 서버 연결 실패
장비: 키오스크
키워드: 키오스크 연결안됨 연결 안됨 서버연결실패 인터넷 아이콘 IP 충돌 방화벽 재시작 접속 끊김
- 1. 인터넷 연결 확인 = 키오스크의 인터넷 연결 아이콘 확인 ※ 아이콘이 ≠ 모양이면 IP 충돌, X 모양이면 연결 끊김
- 2. 프로그램 재시작 = 포스 프로그램 재시작 > 키오스크 프로그램 재시작 ※ 포스 먼저!
- 3. 방화벽 설정 해제
- IP 충돌일 때 = 포스와 키오스크를 서로 다른 고정 IP로 설정 ※ 예) 포스 192.168.0.100 / 키오스크 192.168.0.101 (둘 다 고정 IP), DHCP 범위는 2~99로 두어 충돌 방지. 꼭 100번일 필요는 없음

## 키오스크 연결 안 됨 - 데이터베이스 접속 실패
장비: 키오스크
원인: 포스 IP가 바뀌어서 키오스크에 입력된 포스 IP와 달라진 것
키워드: 키오스크 연결안됨 연결 안됨 데이터베이스 접속실패 DB 포스 IP ipconfig 로컬 IP 접속 끊김
- 핵심 = 키오스크는 포스의 자료를 받아오기 위해 포스 IP를 입력해 둠 > 포스 IP가 바뀌면 접속 실패 ※ 포스 IP가 100이면 키오스크의 로컬 IP 입력란에도 100이 입력되어 있어야 함
- ① 확인 = 포스에서 CMD 실행 > ipconfig /all > IPv4 주소 확인 > 키오스크에 입력한 포스 IP와 같은지 비교 ※ 예) 192.168.0.100
- ② 포스 IP 수정 = 네트워크 공유센터 > 이더넷 > IPv4 속성에서 IP 입력 ※ 예) IP 192.168.0.100 / 게이트웨이 192.168.0.1 / DNS 168.126.63.1(KT 기본). 포스 IP와 키오스크 입력값만 같으면 됨

## 포스가 느려요
장비: POS
키워드: 포스 느림 느려요 버벅 속도 용량 메모리 최적화 임시파일 재부팅
- 용량 정리 = 임시파일 삭제 (윈도우+R → %TEMP%) | C드라이브 용량 확인 | 크롬·멜론 등 무거운 프로그램 종료 | 아크로뱃 리더 삭제 ※ 아크로뱃 리더는 자동 업데이트로 용량을 많이 차지함
- 메모리 최적화 = 작업관리자에서 메모리 점유율 확인 | Windows Defender 끄기 (Winaero Tweaker) | CompatTelRunner.exe 비활성화 | OneDrive 자동시작 끄기 ※ Windows Defender를 끄면 보안이 약해지므로 필요한 경우에만 진행
- 듀얼모니터 = C:\FDKPOS\DUAL\vodfile 삭제 > 이미지로 교체 ※ 재부팅 후 작업
- 디스크 관리 = D드라이브 삭제 > C드라이브 확장(5~7GB) ※ 재부팅 후 작업

## 키오스크 화면이 까매짐
장비: 키오스크
원인: 직사광선
키워드: 키오스크 화면 까매짐 검은 화면 직사광선 어닝
- 해결 (둘 다 적용) = 어닝 설치 | 오전엔 키오스크 방향 조절

## 결제 방식 팁: 빠른결제와 정석
장비: POS
키워드: 결제 팁 빠른결제 정석 신용카드 회원
- 빠른결제 = 메뉴 클릭 > 카드 꽂기 > 바로 결제
- 정석 = 메뉴 클릭 > [신용카드] > 카드 꽂기 ※ 회원 사용 매장은 정석대로 진행

## 포스/키오스크 재설치
장비: POS
장비2: 키오스크
키워드: 재설치 설치 FirstPos 삭제 매출복구 FDK 포스 키오스크 localhost MSXML
- 사전작업 = 포스 프로그램 종료 > 프로그램 추가/제거에서 FirstPos System 삭제 > C드라이브의 FDK_Module, FDK_POS 폴더 삭제 ※ 포스 프로그램 종료는 필수
- 재설치 = FirstPos Setup 실행 > 포스는 localhost 입력, 키오스크는 포스 IP 입력 > MSXML 4.0 SP3 Parser도 함께 설치 ※ 예) 키오스크 입력값: 192.168.0.100 (포스 IP)
- 매출복구 = 환경설정 > 매출자료수신 > 일정 날짜 범위를 지정해서 받기 ※ 비밀번호는 담당자에게 확인
