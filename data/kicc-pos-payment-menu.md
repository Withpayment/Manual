# KICC · POS 메뉴얼 (결제·오더메뉴·회원)
종류: 메뉴얼
VAN: KICC
장비: POS

## EASYPOS › 결제·취소
- 선결제 방식 테스트 = ASP에서 판매형태를 '테이블: 외식후불'로 설정 > 포스 환경설정 > 주문 > 부가기능 > 특이사항 > '강제 선결제 매장 처리' 체크 ※ 후불·선불 테스트를 이렇게 전환함. ASP에서 판매형태를 수시로 바꾸면 DB에 문제가 생길 수 있음
- 취소한 결제의 상품을 판매화면으로 다시 불러오기 = 환경설정 > 매출 등록 > 터치 버튼 기능 설정에서 '판매내역조회' 버튼 배치 > 판매내역조회 > 취소 건 선택 > 결제변경 ※ 판매화면에 내역이 자동으로 뜨고, 현금·카드로 다시 계산하면 새 줄로 올라감
- 분할결제 (메뉴 이동 방식) = 판매화면 > 메뉴 선택 > 분할결제 > 해당 메뉴만 선택 후 화살표로 이동 > 결제 ※ 오더메뉴(오더그룹)가 있으면 오더메뉴까지 같이 선택해서 이동해야 추가 금액이 결제됨(예: 아메리카노 샷추가). 같은 상품 2개는 하나씩 이동됨. 1개 메뉴를 분할결제할 때는 남길 수 없어 분할결제를 끝내야 종료됨
- 분할결제 카드전표 인쇄 (결제 시) = 분할결제 완료 후 영수증 출력 > '카드전표 분할인쇄 하시겠습니까?' 예/아니오 선택
- 분할결제 카드전표 재출력 = 판매내역에서 인쇄 > '영수증을 선택하여 주세요' 창에서 '아니오-고객용' 선택 ※ '아니오-고객용'은 카드전표가 각각 출력되고 '예-카드사용'은 1장으로 출력됨(2025-09-26 기준)
- 개별 할인 = 판매화면에서 해당 메뉴 선택 > 금액 할인 또는 % 할인
- 전체 할인 = '전체선택' 버튼 선택 > 금액 할인 또는 % 할인 ※ '전체선택' 버튼은 선택된 메뉴 목록 아래에 있음
- 서비스 처리 = 단독 메뉴에 서비스 처리할 때 '현금' 또는 '기타결제'를 눌러 처리 ※ 품목 선택만 가능하고 '금액 서비스'는 안 되어 할인으로 처리. 이미 주문된 같은 메뉴가 여러 개면 1개만 서비스가 안 되므로 개수를 수정하고 새로 선택해서 처리
- 서비스·기타결제의 매출 반영 ※ 서비스와 할인은 총매출에 포함. 기타결제는 마감용지에 '전자화폐'로 표기되고 순매출에 포함. '서비스' 누른 뒤 기타결제나 현금으로 처리하면 마감용지에 '서비스'로 표기되고 순매출에 포함되지 않음(할인금액으로 매출요약). 영수증에는 0원으로 표기됨
- 카카오페이 사용 설정 = 포스 환경설정 > 부가설정 > 카카오페이 가맹점2TR, 카카오페이KEY-IN거래 사용 ※ 결제창에 카카오페이 선택 버튼이 생김. IC리더기·단말기 연동 모두 가능. 제로페이는 별도 설정 없이 카드 승인에서 바로 진행됨
- QR코드 인식 설정 = 포스 환경설정 > 부가설정 > 오른쪽 기타설정 > QR코드인식 ※ 카드단말기 연동 시 포스에서 카드>바코드인식을 누르면 단말기가 기본 화면으로 바뀌지만 결제는 정상 진행됨
- 카드단말기 단독 카카오페이 결제 (TS-167N, TS-114A) = 부가1 버튼 > 6.간편결제 > 4.카카오페이 > 바코드란에 숫자 입력
- 프로모션 (1+1, 2+1) ※ 가능하지만 전체 상품에 한 번에 적용할 수 없고 상품별로 한 건씩 등록해야 함. 프로모션이 여러 개는 가능하나 종료된 프로모션을 수정해 재사용하면 안 될 수 있으며, 안 되면 환경설정>화면>기타화면설정>왼쪽 아래 '프로모션 중복적용 확인처리'를 확인
- 더치페이 결제 = 판매화면의 더치페이 버튼 > 인원수 선택(자동 계산) ※ 기본 버튼이 아니라 매출등록에서 터치키로 추가해야 함. 영수증은 한 장이고 중간에 빠져나올 수 없어 반드시 결제를 완료해야 함(강제 종료하면 반품에 저장되지 않음). 중단해야 하면 나머지 금액을 현금으로 처리한 뒤 반품하고 다시 결제
- 카드결제 임의등록 비밀번호 해제 = 환경설정 > 부가설정 > 임의등록 패스워드 체크 해제 ※ 비밀번호는 별도 안내. 마감용지에는 실제 카드 결제를 임의등록 처리한 건만 '임의등록'으로 표기됨(현금·카드로 임의등록한 건은 표기 안 됨). 영수증/반품의 '임의반품' 표시는 삭제되지 않음
- 교차취소 (다른 단말기 승인 건 취소) ※ 주로 주유소에서 쓰는 방식. 일반 포스 가맹점은 TID를 동일하게 쓰므로 포스 TID 하나로 포스·카드단말기를 다운로드하면 카드 취소가 됨(테스트 확인). 중요: KICC 전산 단말기정보에서 '다운로드허용여부'가 Y여야 함
- 테이블에서 일부만 먼저 결제(선결제) ※ 설정이 필요함(원문에 그림으로 안내되어 위치 확인 필요). 설정하지 않으면 나머지 금액까지 결제되어 계산이 끝나버림. 분할결제 버튼으로 한 건씩 결제하면 설정 없이도 정상
- 티머니(교통카드)·페이코 결제 (포스) ※ 티머니는 포스에서 가능하지만 NFC 단말기를 추가로 설치해야 함. 페이코는 바코드 스캐너를 추가로 설치
- 앱카드(신한쏠) QR·바코드 결제 설정 = 환경설정 > 부가기능 > 오른쪽 'QR사용' 체크 ※ 스캐너(예: YJ2000 USB 2D)로 QR·바코드 결제가 되고, QR로 결제해도 취소할 때는 바코드가 뜸
- 앱 바코드 번호로 결제 = 바코드 아래 번호를 입력(화면 반응 없음) > 키보드 엔터 ※ 마지막에 키보드 엔터가 꼭 필요하고 화면의 숫자·버튼은 적용되지 않음. '바코드키인' 버튼은 카카오페이만 되는 것 같음
- 앱 바코드 번호로 취소 = 앱에서 해당 건 들어가 결제취소를 눌렀을 때 뜨는 바코드 번호를 카드번호란에 입력 > 엔터 ※ 바코드 번호는 결제할 때마다 다름. 앱 상단 타임라인에서 해당 건 확인
- 카드를 미리 꽂았을 때 자동 결제 막기 = EzMSR와 이지포스 프로그램 종료 > C:\KICC\EzMSR2\Option.ini 열기 > EASYPOS=Y 줄을 삭제 또는 N으로 > S_AUTO=Y 확인 > 포스 재부팅 ※ 최신 버전은 기본이 자동결제가 안 되게 되어 있음. 반드시 포스를 재부팅하고, 다시 Y로 바꾸면 미리 꽂기가 됨. 복합결제로 카드 2개를 나눌 때 두 번째 카드가 바로 결제되지 않아 X로 나갔다가 카드 버튼을 다시 눌러야 하고 취소 시 두 번째 카드는 IC/RF 버튼을 눌러야 함. KICC 고객센터는 권장하지 않는다고 안내함(2024-02-14, EzMSR 업데이트 후 문제가 생긴 적이 있음)
- 반품 후 상품 재등록 확인창 = 환경설정 > 부가설정 > 오른쪽 '반품 후 상품 재등록 여부(확인창)' 체크 ※ 영수증반품이나 반품(임의반품) 후 '결제한 상품을 다시 등록하시겠습니까?' 창이 뜸. 상품 금액을 꼭 확인할 것
- 현금영수증 발행 - 카드로 발행 = 카드 꽂기 > 창의 'IC/RF 카드요청' 누르기 ※ 취소할 때는 서명패드에 번호 입력창이 뜨지 않음. 번호로 발행한 건은 취소 시 번호 입력 없이 바로 취소됨
- 현금영수증 발행 - 신용카드로 발행 = 리더기에 카드 삽입 > 승인/자진발급 버튼
- 현금영수증 자진발급 = 번호를 누르지 않고 '승인/자진발급' 버튼만 누르기 ※ 대리점ASP>가맹점관리>설정>현금영수증자진발급을 '사용'으로 설정해야 함
- 애플페이 결제 (EP-736) ※ EzMSR를 쓰지 않아 카드를 미리 꽂고 결제하는 것은 안 됨. 현금 버튼이 3~5초 늦게 올라옴. 리더기(EzMSR)로 되돌릴 때는 포스를 켰을 때 자동 실행되는지 확인하고, 자동 실행이 안 되면 기존 것을 삭제하고 재설치
- 애플페이 단말기에서 현금영수증 - 카드 = 카드 투입 > 승인/자진발급 버튼
- 애플페이 단말기에서 현금영수증 - 번호 입력 (카메라창이 먼저 뜰 때) = 인식번호입력 버튼 > 서명패드 번호창 > 번호 입력 > 승인/자진발급 버튼
- 복합결제 건의 취소 방법 = 해당 건은 전화취소 또는 카드단말기로 별도 취소 > 포스에서 전체를 임의반품 처리 > 남은 내역만 임의등록으로 올리기 ※ 복합결제는 완료되어야 영수증반품에서 보임(분할결제로 해당 상품만 결제한 건은 영수증반품에 올라옴). 판매내역조회의 '결제변경'은 '일부변경'으로 카드 2개 중 1개만 취소되고 다른 카드로 다시 승인하면 매출에는 전체가 반품으로 남음. 고객센터는 권장하지 않는다고 함
- '일부변경' 안 보이게 설정 = 환경설정 > 부가설정 > 부가설정 > 기타결제처리부가기능(오른쪽)
- 카드 할부 방법 = 할부개월수 입력 > 서명패드에 서명 ※ 카드를 미리 꽂은 경우에도 동일. 서명하기 전에는 결제 대기 상태임
- 수표 조회 = 환경설정 > 매출등록 > 터치버튼기능설정 > 수표조회 선택 > 저장 ※ 수표 메뉴가 안 보이면 설정해야 함
- 기타결제 버튼 ※ 마감용지에는 '전자화폐'로 표기되고(시재 현금에 포함되지 않음) ASP에는 '기타'로 표기됨
- 현금영수증 사후승인 = 결제 후 판매내역에서 '국세청현금영수증' 발행 ※ 필독: 사후승인은 포스에서 취소가 안 되고 단말기 또는 전화로 취소해야 함('영수증반품'에서 해도 매출만 반품되고 실제는 취소되지 않음). 식별번호가 있는 영수증은 재출력이 안 되고(상품만 있는 영수증만 출력) 전산 또는 ASP에서 확인해야 함
- 현금영수증 자진발급 - 방법 1 (기본 설정) = 현금 > 소득공제용 체크 > 휴대전화번호 입력 > 승인/자진발급 버튼
- 현금영수증 자진발급 - 방법 2 = 현금 > 승인/자진발급 버튼 ※ 설정: ASP>가맹점조회>설정>현금영수증자진발급 '사용'
- 복합결제 선결제 시간차 - 방법 1 (연속 결제) = 환경설정 > 주문 > 부가기능 > (사용함) 연속으로 결제 ※ 나머지 결제까지 반드시 완료해야 함
- 복합결제 선결제 시간차 - 방법 2 (시간차 결제) = 환경설정 > 주문 > 부가기능 > (사용함) 선결제를 기본으로 시간차 결제 > 1건 결제 후 '주문'을 누르면 테이블에 반영 ※ 단점: 1건만 결제해도 '퇴실처리 하시겠습니까'가 뜸. 먼저 결제된 테이블(금액이 남은 테이블)과 일반 테이블은 이동해 합칠 수 없고 '선불결제할 내역이 있는 경우 주문내역이 있는 테이블로 이동이 불가능합니다'가 뜸(그냥 이동은 됨). 그룹결제는 되나 그룹 안에서 복합결제는 안 됨
- 핸드스캐너로 네이버페이 결제 = 카드 > QR 창 띄우기 > 스캐너 읽기 ※ 카카오페이는 카드>스캐너 읽기만 하면 바로 승인됨
- 결제금액 끝전 처리 (10원 이하 버림) = 판매화면에 '결제금액 끝전처리' 기능키 진열 > 메뉴 선택 > 결제금액 끝전처리 > 카드 또는 현금 ※ 예: 11,111원은 11,100원으로 처리. 반올림·올림·원단위 설정은 없고, 메뉴를 선택하면 자동으로 처리되는 방법도 없음. ASP>기초정보관리>가맹점관리>가맹점조회 '설정'의 끝전위치·끝전처리방법은 이벤트·프로모션용
- 카카오페이 비가맹 승인 (하나카드사 매입, 2026-09-20 기준) ※ 추가 핸드스캐너 결제 방식. 포스는 QR 결제가 되고 추가 설정이 없으며, 네이버 커넥트를 연결해서도 결제됨(2026-10-21 테스트). 환경설정>부가설정의 카카오페이 가맹점 2TR, QR 사용 여부를 체크하지 않아도 잘 됨. 카드단말기 단독도 QR 결제가 되고 추가 설정이 없음

## EASYPOS › 회원·외상
- 외상 처리 = 판매화면 > 외상 > 고객조회 > 등록 ※ 고객 등록 없이도 외상 처리는 가능하고 매출에 포함됨. 분할결제에서 외상과 현금을 나눌 수 있음
- 외상 수금 = 메인화면 > 외상입금 > 날짜 선택 > 현금 또는 카드 결제 ※ 당일 건은 판매내역의 결제변경(반품되면서 메뉴가 다시 뜸)으로 현금·카드 결제해도 되고, 외상입금에서 자동으로 사라짐
- 외상 조회 (포스) = 메인메뉴 > 자료조회 > 원격자료조회 > 29.외상매출내역 또는 31.고객별외상집계 ※ 외상 내역은 구매이력과 같은 메뉴에서 조회되지 않음
- 외상 조회 (ASP) = 영업속보 > 기타결제수단별 > 외상입금내역조회 및 입금등록
- 외상 수금을 실수로 했을 때 ※ 수금 후 영수증반품하면 매출과 외상수금에서 모두 없어지지만, 마감정산의 '외상입금액'은 남아서 현금으로 수금한 경우 과부족이 +로 보임(2024-07-02 기준)
- 회원(고객) 등록 방법 = 포스 | 키오스크 | ASP ※ 카드번호는 중복 체크됨(휴대폰번호는 같은 번호로 여러 번 가능). 고객명은 필수가 아니고 휴대폰번호와 카드번호가 필수(휴대폰번호를 카드번호로 같이 사용 가능). 결제를 취소하면 포인트가 자동 차감됨
- 포스에서 신규 가입할 때 ※ 먼저 휴대폰 뒷번호로 검색한 뒤 등록. 키오스크 가입 시 휴대폰번호 맨 뒤 4자리가 고객명이 되고 카드번호는 자동 등록되지 않음
- 고객 개인정보 표시 ※ 영수증과 포스 화면에는 이름·휴대폰번호가 개인정보라 더 이상 출력되지 않음. ASP에서 고객 삭제는 안 되고 '사용중지'로 설정
- 상품별 포인트 적립 = ASP > 고객관리 > 고객등급관리 > 고객등급에서 선별적립 선택 > 고객선별상품등록에 상품 추가 ※ 선별한 상품만 포인트가 적립되고, 포인트 차감(할인)은 모든 상품에 적용됨
- 사용 중지된 고객 다시 사용 = ASP > 고객관리 > 고객조회 > 고객현황조회에서 사용구분을 '미사용'으로 설정 후 조회 > 하단 '재사용' 클릭
- 선결제(선수금)로 고객 포인트 사용 = 단말기에서 금액 입력 후 결제(포스 매출 아님) > 포스에서 고객 등록 > 결제한 금액만큼 포인트 등록 > 결제 시 차감 ※ 판매화면에 '고객포인트처리' 메뉴키를 진열하면 편함. 영수증에는 개인정보라 고객명 일부만 보이고 카드번호는 숫자로 출력되지 않음. ASP 조회 기간은 180일 제한
- 포인트 가산·감산 비밀번호 = 포스 환경설정 > 부가설정 > 고객포인트설정 > 추후적립패스워드체크함 ※ 비밀번호는 별도 안내. 변경 불가(고정값)
- 고객정보·포인트가 포스에 반영되지 않을 때 = 포스에서 '기초정보수신' 누르기 ※ ASP 또는 포스에서 고객정보를 수정하거나 포인트를 등록한 뒤 반영이 안 될 때
- 신규 고객 등록 시 카드번호 제외 = 환경설정 > 부가설정 > 고객포인트설정 > '신규고객등록 시 카드번호제외' 체크
- 직원 할인 설정 (ASP 고객 등급) = ASP > 고객관리 > 고객등급관리 > 등급 추가: 할인구분 '선별할인 10%' > ASP > 고객관리 > 고객선별상품등록(적립금) > 선별 상품 추가 후 저장 ※ 상품등록에서 가격을 바꾸면 변경된 가격으로 반영됨. 상품 분류 단위 할인은 안 됨
- 직원 할인 사용 방법 (포스) = 고객 선택 > 할인이 설정된 메뉴 선택 > 판매화면에 할인금액 표시 > 카드 또는 현금 계산

## EASYPOS › 오더메뉴
- 메인메뉴 수량 변경 시 오더메뉴도 자동 변경 = 포스 환경설정 > 화면 > 기타화면설정 > 오더그룹 기능 우선사용 체크 ※ 세트 오더그룹 필수 선택·다중 선택 상품에서 메인메뉴 수량만 바꿔도 오더메뉴가 같이 바뀌게 하는 설정
- 포스에서 계산 시 오더메뉴 수량 변경 (ASP) = ASP 상품관리 > 오더관리 > 해당 오더분류 선택 > '부가메뉴 일괄변경: 사용' ※ +, - 또는 키패드로 수량 변경 가능. ASP 오더관리 설정에 따라 약간 다름
- 포스에서 계산 시 오더메뉴 수량 변경 (포스) = 환경설정 > 화면 > 기타화면설정 > 오더그룹 기능 우선 사용 체크 > 최대수량필수선택 사용안함(세트메인여부) 체크
