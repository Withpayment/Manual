# KIS · 카드단말기 모델별 공식 매뉴얼 정리
종류: 메뉴얼
VAN: KIS
장비: 단말기

## KIS-3210 › 카드 승인
모델: KIS-3210
- IC 카드 승인 = 초기화면 > IC카드 삽입 > 금액 입력 > 결과 및 전표 확인
- 현금영수증 = 현금/한영 > 1.소비자소득공제 > 번호 또는 카드 입력 > 금액 입력
- 원본 설명서 = https://www.kisvan.co.kr/product-data/KIS-3210.pdf

## KIS-3210 › 카드 승인 취소
모델: KIS-3210
- 직전 거래 취소 = 취소/숫자 > 1.직접취소 > 직전 거래 확인 > 카드 확인
- 일반 신용 취소 = 취소/숫자 > 2.신용취소 > 카드 정보 > 원승인번호 > 원거래일자 > 금액
- IC 취소 = 취소/숫자 > 2.신용취소 > IC카드 삽입 > 원승인번호 > 원거래일자 > 금액
- 주의 = 취소 전 원거래 내역과 금액을 반드시 대조
- 원본 설명서 = https://www.kisvan.co.kr/product-data/KIS-3210.pdf

## KIS-1420 › 사용자 설정
모델: KIS-1420
- 할부 설정 = 기능 > 1.사용자설정 > 1.할부설정 > 0.사용
- 부가세 설정 = 기능 > 1.사용자설정 > 2.부가세설정 > 0.사용
- 인쇄 매수 설정 = 기능 > 1.사용자설정 > 7.인쇄기능설정 > 1.인쇄매수설정
- 원본 설명서 = https://www.kwinfo.co.kr/uploadfiles/2021/09/20210908160828253.pdf

## KIS-1420 › 결제 및 영수증
모델: KIS-1420
- IC 카드 승인 = 승인 > 1.신용 > IC카드 삽입 > 금액 입력
- 현금영수증 = 현금 > 1.소비자소득공제 > 번호 입력 > 금액 입력
- 재인쇄 = 초기화면 > 재인쇄 키
- 원본 설명서 = https://www.kwinfo.co.kr/uploadfiles/2021/09/20210908160828253.pdf
