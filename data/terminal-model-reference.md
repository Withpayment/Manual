## KPN › 공식 등록 유선 단말기 모델 구분
VAN: KPN
모델: KPN-7201 / KPN-3103 / MPOS-1901AE / MPOS-1700AE / MPOS-1902TE
키워드: KPN 유선 단말기 모델 찾기
- KPN-7201 = 캐시노트 페이 결제 단말기
- KPN-3103 = 3인치 유선 카드단말기
- MPOS-1901AE = 컴팩트 3인치 단말기
- MPOS-1700AE = 3인치 유선 단말기
- MPOS-1902TE = 2인치 유선 단말기
- 주의 = 모델 확인 전 다른 모델의 관리자 메뉴·용지 규격·전원 사양을 적용하지 않기
- 공식 모델 목록 = https://www.kpn.co.kr/offline/product.do?code=CD001

## KPN › 공식 등록 무선 단말기 모델 구분
VAN: KPN
모델: MPOS-2300M(S) / KPN-1202 / KPN-6205

- 공식 모델 목록 = https://www.kpn.co.kr/offline/product.do?code=CD001
- KPN-6205 시작 안내 = https://cashnotepay.oopy.io/ee373215-b409-4629-938e-5718567a2015

## KIS › KIS-2420 연결 방식과 POS 연동 확인
VAN: KIS
모델: KIS-2420
키워드: KIS-2420 통신 LAN 전화선 PSTN POS 연결 전원
- 통신 방식 = Ethernet 전용이며 PSTN 전화선 통신 불가
- 프린터 = 3인치 써멀 전표(70mm 또는 80mm)
- 전원 = DC 24V / 2.5A
- 인터페이스 = Ethernet, USB Host 및 Serial 포트 제공
- 주의 = 전화선 포트가 있다고 가정하거나 다른 모델 어댑터를 혼용하지 않기
- 공식 제품 정보 = https://www.kisvan.co.kr/sub02_01_02.html

## KIS › KIS-3210 연결 포트 및 전원 확인
VAN: KIS
모델: KIS-3210
키워드: KIS-3210 포트 LAN POS 전화선 전원 어댑터
- 통신 포트 = Ethernet(LAN) / POS 표기 포트 / 전용선 / 핀패드 / 전화기 / 전화선
- 전원 = DC 9V / 3A
- 프린터 = 2인치 써멀 전표(약 50mm)
- 확인 순서 = 장비 후면 모델명 확인 > 사용 중인 연결 포트 확인 > 해당 통신선 체결 확인
- 주의 = KIS 공식 제품 페이지에서 2인치 단말기는 POS 연동 불가로 안내함 ※ 물리적인 POS 표기 포트와 POS 연동 지원은 별개이며 KIS-2420의 24V 어댑터와 혼용 금지
- 공식 설명서 = https://www.kisvan.co.kr/product-data/KIS-3210.pdf
- 공식 제품 정보 = https://www.kisvan.co.kr/sub02_01_03.html
