## EASYPOS › 설치·업데이트
- 원격지원 실행 = 이지포스 메인화면의 '원격지원' 클릭 ※ 또는 윈도우 바탕화면의 '한국정보통신' 아이콘 클릭
- 프로그램 최신 버전 업데이트 = KICC 고객센터에 전화해서 업데이트 요청 ※ 2023-06-02 기준 ver 4.3.5.501. 환경설정은 그대로 유지됨
- 윈도우10 msxml 파서 파일 ※ ASP>자료다운로드의 참고 목록 51번, 64번, 76번 (이지포스·키오스크 설치 파일과 동일)
- 상호·주소·전화번호가 바뀌었을 때 = 스마트오피스(전산)와 ASP에서 변경 > 이지포스 재실행 ※ 포스, 키오스크(윈도우/안드로이드), 탭 공통(2023-12-08 테스트)
- 사업자번호가 바뀌었을 때 ※ 재인증
- 본부코드·지점코드와 사업자번호가 함께 바뀌었을 때 ※ 재설치
- 가맹점번호(상호)가 바뀌었을 때 - 카드단말기 갱신 = 특수 버튼 > 4.TMS > 7.가맹점정보갱신 > '갱신되었습니다' 메시지 후 메인 화면
- 가맹점번호(상호)가 바뀌었을 때 - 카드단말기 다운로드 ※ 다운로드를 하면 설정이 초기화됨. 포스는 추가 작업이 없음
- 부팅 시 프로그램 자동 실행 = 윈도우+R > shell:startup 입력 ※ 안 될 때는 원문의 이미지를 참고해야 함(확인 필요)
- 포스 교체·재설치 시 백업 파일이 없을 때 = ASP 환경설정에서 환경설정 XML의 해당 포스번호 01 내용을 복사 > PosEnv.xml에 붙여넣기 > 메모장에서 맨 위 encoding을 UTF-8에서 euc-kr로 수정 ※ 설치 후 개점할 때 사원 리스트와 사원명이 안 뜨면 마스터를 삭제하고 이지포스 프로그램을 재실행
- 포스 버전 다시 받기 = C:\Program Files\EasyPOS\dat\PosVersion.xml 삭제 > 이지포스 프로그램 실행(5분쯤 소요) ※ 포스를 켜고 처음 로그인하면 '삭제64파일'이 1초쯤 뜨는데 정상(업데이트되면서 기존 광고 이미지 등을 삭제하고 ASP에서 새로 받는 메시지). 인터넷은 되는데 첫 로그인 화면에 광고가 안 뜨고 하얗게 나올 때 해 보기(프로그램을 재실행하면 광고가 뜸)
- 포스 전원 자동 끄기 (작업 스케줄러) = 윈도우+R > taskschd.msc > 작업 스케줄러 라이브러리 > 작업 만들기 > 일반 탭 이름 POSPowerOff, '가장 높은 수준의 권한으로 실행' 체크 > 트리거 탭 새로 만들기: 매일 22:00:00 > 동작 탭 프로그램 시작: 프로그램 shutdown, 인수 /s /f /t 0 > 조건 탭 '컴퓨터의 AC 전원이 켜져 있는 경우에만 작업 시작' 체크 해제 ※ 인수의 띄어쓰기에 유의
- 포스 전원 켜짐·꺼짐 이력 확인 = win+R > eventvwr.msc > Windows 로그 > 시스템 > 오른쪽 '현재 로그 필터'에서 이벤트 ID 확인 ※ 6005: 윈도우 시작(PC 켜진 시간), 6006: 정상 종료(PC 정상 종료 시간), 6008: 비정상 종료(전원 강제 끔), 41: 갑자기 전원이 꺼짐

## EASYPOS › 장비·연동
- 리더기 대신 단말기로 결제 (리더기 인식이 안 될 때) = EzMSR2 삭제 또는 종료 > 단말기 설정 변경(특수 > 부가장치 > 2.POS) > 포스 환경설정 > 장비 > 싸인패드 설정 정리 ※ 서명패드는 단말기에 연결되어 있어야 함. 포스에 서명패드가 연결되어 있으면 5만 원 이상 결제와 현금영수증이 안 됨. 포스 연결 시에는 환경설정>장비>싸인패드를 '사용안함'으로 하면 서명·현금영수증 없이 결제됨. KICC 서명패드는 연결 포트가 1개뿐이라 포스 연결을 권장. 원문 일부만 반영
- 듀얼모니터 동영상 설정 = 듀얼모니터 사용 > 재생형태 MPG > 해상도 1024x768 > 파일명 Default.mpg > 소리 재생 사용안함 > 플레이어 VLC > 화면 채움 ※ 듀얼 화면의 글씨는 크게 할 수 없고 CDP/DUAL 듀얼모니터는 MPG 동영상만 가능. 영상 파일 폴더는 C:\Program Files\EasyPOS\dat. 포스 환경설정이 1024x768이어야 화면이 꽉 참
- 듀얼모니터 이미지 등록 = ASP > POS관리 > POS이미지관리 > '+'로 jpg 파일 첨부 ※ 이미지는 ASP에서만 등록 가능하고 파일명은 상관없음. 크기는 800x600 권장(너무 크면 끊김)
- 현금 거스름돈 계산 시 돈통 열기 = 환경설정 > 장비 > 돈통을 영수증프린터연결 또는 시리얼제어로 설정 ※ 환경설정>화면의 '거스름돈 팝업 사용안함'(왼쪽 아래)이 체크되어 있지 않아야 함
- ASP 연결 브라우저를 크롬으로 변경 = 포스 환경설정 > 통신 > 맨 위 오른쪽 '크롬브라우저실행여부(자동로그인)' 체크 ※ 메인메뉴>영업정보관리를 눌렀을 때 열리는 브라우저가 익스플로러에서 크롬으로 바뀜. 일부 ZED 포스는 파이어폭스로 열어야 ASP 글씨가 정상으로 보이고, 히트플러스 윈도우10에서는 크롬·엣지가 열려도 정상으로 뜨지 않음(2026-09-10 기준)
- EP-736 멀티패드 단말기 업데이트 ※ D0008 버전으로 업데이트하면 '삼성페이가 결제 후 취소되는 오류'가 패치됨(2024-06-26)
- SWT-1100 인쇄 프린터 연결 ※ 포스에서 인쇄용으로 용지 출력이 잘 되지만 연결 케이블(PC 연동선)에 따라 출력이 안 될 수 있음. 최근 케이블을 쓰고 핀 색이 선명하며 핀이 보이는 면적이 넓은 것을 사용
- KS1030 단말기 연동 - 단말기 설정 = 단말기 버전 표준 S.02G > 포스연동 설정 속도 38400 ※ 연동 케이블은 Y자형(돈통, 단말기 PS2, 시리얼). 영수증프린터·주방프린터·돈통(금전함) 모두 정상 동작
- KS1030 단말기 연동 - 포스 설정 = 포스 속도 38400 > 도시바로 영수증·주방프린터 같이 출력 ※ 주방프린터가 1개 더 있어도 같이 출력됨
- 포스 교체 시 고정 IP (IPTIME 공유기) = 공유기 관리자 접속 > 기존 포스의 MAC 주소 삭제 > 새 포스에서 고정 IP 설정(기존 IP 입력) ※ 인터넷이 잠깐 끊겼다가 다시 붙고 원격도 다시 연결됨. Ping 테스트로 다른 기기가 쓰는 IP인지 확인. 포스에 IP를 고정하다 인터넷이 안 되면 굳이 할 필요 없음(자동 사용). IPTIME 고객센터 안내로는 공유기에만 등록되어 있으면 됨. IPTIME 공유기는 모뎀·공유기를 재부팅해도 IP가 바뀌지 않고 KT 공유기는 바뀜. 테이블오더가 아닌 포스·키오스크 매장은 새 IP를 키오스크나 주문포스에 수정해야 함
- 13자리 고정 바코드 스캐너 - 사용 가능한 모델 = 지브라 ZEBRA DS2208(핸드스캐너) | 사이퍼랩(핸드스캐너) ※ 타임바코드·일배식품 같은 13자리 고정 바코드용. 지브라는 판매처에서 13자리 세팅을 해 주며(엔터값 확인: 메모장에 찍었을 때 바코드 밑 칸으로 이동), 사이퍼랩은 별도 세팅 값이 필요함
- 13자리 고정 바코드 스캐너 - 안 되는 모델 = MS7120(데스크 스캐너) | YJ2000(핸드스캐너) | 송우전자 EK-111 키오스크 | 하나시스 K-220D 키오스크
- 시리얼 스캐너 설정 = 환경설정 > 장비 > 스캐너 > 스캐너 제어형태 '시리얼제어' > 시리얼포트번호 선택
- EP-763 멀티패드 포스 업데이트 (2025-05-14, 버전 D0037) = 포스에서 업데이트(KICC ASP 자료실의 EP-705, EP-731N, EP-763 업데이트 안내) > 시리얼로 '업데이트 펌웨어 다운로드(8BIN)' 파일 선택 ※ 멀티패드에서는 설정하지 않으며 10분쯤 걸릴 수 있음
- MS-7120 데스크 스캐너 (포스 시리얼) = 환경설정 > 장비 > 스캐너 > 스캐너제어형태 '시리얼 제어' > 시리얼포트번호(COM 포트) 지정 ※ 시리얼 속도(bps)를 지정하는 항목은 없음

## EASYPOS › 부가기능
- 배달 CID(콜스타) 주소검색 방식 = 환경설정 > 배달주문 > 주소검색방식을 '다음웹검색'으로 ※ CID 연동 참고 파일은 별도 자료실에서 받아야 함
- DID(대기번호 표시) 환경설정 진입 = 설치 후 번호가 뜨는 화면 맨 오른쪽 하단 여백 터치 ※ 홈 버튼은 맨 위 왼쪽 상단 여백 터치. 준비중/준비완료로 넘어갈 때 짧은 비프음이 남. 포스에 DID에 설정한 고정 IP를 설정해야 하고, 윈도우7은 잘 안 될 수 있어 윈도우10 64비트를 권장
- DID 선결제 매장 운영 방식 = 포스 결제 > 호출번호창에서 번호 입력 > DID '준비중'에 번호 표시 > 포스에서 DID호출 메뉴 > 호출 눌러 호출 완료 > DID '준비완료'로 번호 이동 ※ DID를 재부팅해도 호출 번호는 남아 있음
- 이지포스모바일(이지샵) EasyShop Mobile (무료) ※ 카드단말기만 사용하는 가맹점용이며 회원가입은 앱에서 해야 함
- 이지포스모바일 (무료) ※ 판매상품 분류와 집계는 확인되지 않음
- 이지포스모바일 Pro (유료) ※ 후불제 실시간 주문 테이블 확인, 계정관리로 가맹점 1개 이상 추가(본부코드가 달라도 가능), 상품 등록(수정은 되고 삭제는 안 됨), 단품실사·무발주입고 등록과 확정, 마감·카드반품 푸시 알림(설정>알림설정에서 끌 수 있음). 유료 앱이 부담되면 삼성 휴대폰 보안폴더에 앱을 추가해 계정 하나를 따로 확인하는 방법도 있음
- 휴대폰 앱 재고 등록 (유료 앱만) = 주문재고 > 단품실사등록 > 단품실사확정 ※ 확정되면 추가 등록·수정이 안 됨
- 휴대폰 앱 입고 등록 (유료 앱만) = 주문재고 > 무발주 입고등록 ※ 저장하면 확정됨. '무발주 입고관리'에서는 입고 처리한 목록을 삭제(입고 취소)하거나 다시 확정(입고 처리)함. 헷갈리면 목록을 하나씩 눌러 처리구분의 '취소' 또는 '확정'을 확인
- 알림톡(카카오톡) - 진동벨·대기번호 호출 ※ 안드로이드·윈도우 키오스크 모두 호환됨. 카카오톡을 쓰지 않는 사람에게는 문자로 전송됨(테스트 때 카카오톡을 삭제하니 문자는 오지 않았고, 가입이 안 되어 있어야 문자가 가는 것 같다고 함. 나중에 PC에서 카카오톡에 로그인하면 알림을 받음). ASP 알림톡은 선불식과 충전식이 있어 대리점에서 가맹점에 맞게 설정함. 선불식은 남은 알림 개수가 '알림톡호출' 창 맨 아래에 뜬다고 하며, 안 뜨면 지우고 다시 해보기(선불·후불 설정을 번갈아 테스트하면 안 뜰 수 있음). 설정 전에 ASP에 충전이 되어 있어야 함
- KDS(주방 디스플레이) ※ 윈도우에서는 안 되고 안드로이드에서만 됨(2025-04-01 기준). 이미 설치된 이지포스에서 설정만 KDS로 바꾸면 되며 윈7·윈10 상관없으나 포스 설치 파일이 오래된 버전이면 안 됨(설치 파일은 ASP 자료실). 포스 선결제 매장도 가능. KICC 안드로이드 포스 장비(CS-273, CS-273N, TS-194 등)에서 설정할 수 있고, 일반 태블릿에서 EasyKDS를 구동할 때는 KICC 포스 사업부에 문의해야 함(OS 제한 등)
- 네이버 예약 연동 ※ 설정과 동시에 반영되며 접수 시 알림음은 없음. 이지포스와 별개로, 예약이 들어오고 5분 안에 확정·취소하지 않으면 안내 전화가 오도록 설정됨. 네이버 앱 알림이 오지 않으면 앱 자체 알림 설정이 꺼져 있는지 확인. 설명서는 KICC 자료(서비스연동 화면, 포스연동 화면) 참고

## EASYPOS › 설치·업데이트 › 포스 설치·설정 체크리스트
- 참고 필독 - 기본 동작 ※ 인터넷이 끊겨도 프로그램은 실행됨. 설정 후 정상 작동하지 않으면 프로그램을 재실행. 포스가 여러 대면 포스마다 환경설정을 각각 해야 함(주방 1, 2). 선결제 기능은 사용 체크. 키오스크 음성 안내도 확인

- 단독/멀티 설정 - 윈도우 포스 + 윈도우 키오스크 = 단독POS 설정 ※ 둘 다 윈도우면 단독으로 설정(포스를 멀티로 잡으면 꼬일 수 있음). 윈도우 키오스크는 단독으로 운영
