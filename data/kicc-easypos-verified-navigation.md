## EASYPOS › ASP › 터치키 › 상품 추가
모델: EASYPOS (공개 가이드 2024-02-26 기준)
키워드: 이지포스 터치키 상품 추가 메뉴 버튼 진열
- 진입 = 판매화면 X > 영업정보관리 > 기초정보 > 터치키관리 > 터치키상품등록
- 분류 선택 = 조회 > 터치키 분류 선택 > 오른쪽 상품 추가 버튼
- 상품 검색 = 상품명 또는 상품 분류 선택 > 조회 > 추가할 상품 체크 > 선택
- 저장 = 추가된 상품 확인 > 저장 > 확인
- POS 반영 = POS 판매화면으로 돌아가기 > 기초정보수신 > 영업등록
- 출처 = https://www.kmisys.com/Manual/?bmode=view&idx=18186189

## EASYPOS › ASP › 터치키 › 상품 위치 변경
모델: EASYPOS (공개 가이드 2024-02-26 기준)
키워드: 이지포스 터치키 위치 이동 순서 페이지 안보임
- 진입 = 판매화면 X > 영업정보관리 > 기초정보 > 터치키관리 > 터치키상품등록(위치)
- 위치 변경 = 터치키 분류 선택 > 상품 드래그하여 원하는 위치에 놓기 > 저장 > 확인
- 다음 페이지 확인 = 상품이 안 보이면 오른쪽 화살표로 다음 페이지 확인 ※ 다른 페이지에 배치된 상품은 페이지 이동 기능으로 옮기기
- POS 반영 = 기초정보수신 > 영업등록
- 출처 = https://www.kmisys.com/Manual/?bmode=view&idx=18186189

## EASYPOS › ASP › 주방프린터 › 출력 상품 선택
모델: EASYPOS (공개 가이드 2024-05-03 기준)
키워드: 이지포스 주방프린터 메뉴 안나옴 특정 상품 출력
- 진입 = 영업정보관리 > POS관리 > 주방프린터 관리
- 대상 조회 = 매장터치키 등록상품만 체크 해제 > 조회 > 프린터번호 선택
- 출력 상품 선택 = 출력할 상품 체크 > 출력하지 않을 상품 체크 해제 > 저장
- POS 반영 = POS 화면에서 기초정보수신
- 출처 = https://www.kmisys.com/Manual/?bmode=view&idx=21248487
