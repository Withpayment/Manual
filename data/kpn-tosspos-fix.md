# KPN 문제 해결 (토스POS)
종류: 문제해결
VAN: KPN
모델: 토스POS

## 토스POS에서 포인트 적립 시 번호를 잘못 입력함
장비: POS
키워드: 포인트 적립 번호 오입력 잘못 입력 고객정보 삭제 차감 수정
- 방문 이력 없는 고객정보 = 왼쪽 위 메뉴 > 포인트·스탬프 > 고객정보 > 해당 고객 선택 > 삭제 ※ 전화번호만 등록되고 방문 이력이 없는 손님은 매장에서 삭제할 수 있음. 버튼의 세부 위치는 기기 화면 확인 필요
- 방문 이력 있는 고객정보 = 고객 본인이 카카오 채널 토스오더 > 마이페이지 > 설정 > 매장별 수신 동의 > 해당 매장 삭제 ※ 고객 본인 확인이 필요하므로 사장님이 임의로 삭제하지 말 것
- 삭제 전 주의 = 해당 매장의 적립 내역과 쿠폰도 삭제되고 복구되지 않음 ※ 포인트·선불권 잔액 확인
- 오적립 포인트 조정 = 고객 정보 삭제와 별개 문제. 포인트 차감·재적립 등 가능한 정정 방식은 거래 및 고객 본인 확인 후 토스플레이스 고객센터에 문의
- 공식 안내 = https://guide.tossplace.com/operate/customer-management

## 결제 취소 후 원거래 내역 영수증 요청
장비 : POS
키워드 : 취소영수증 취소전영수증 결제영수증 원거래영수증
- 토스포스내에서는 원거래 영수증 출력 기능이 없음
- 영수증은 고객 요청 시 VAN사 전산에서 확인 후 이메일 또는 문자로 발송 가능하며, POS 단말기에서는 직접 출력 기능이 제공되지 않음을 안내해야 함
