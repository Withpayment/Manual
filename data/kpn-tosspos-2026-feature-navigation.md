# 토스포스 2026 신규 기능·공식 가이드 메뉴 트리 보강
종류: 메뉴얼
VAN: KPN
장비: POS

## 토스POS › 상품·할인 › AI 사진으로 상품 한 번에 추가
모델: 토스POS (2026-11-26 공식 고객지원 가이드 확인)
키워드: AI 상품 등록 메뉴판 사진 손글씨 포스 화면 카테고리 옵션 일괄등록
- 메뉴 진입 = 왼쪽 위 메뉴 > 상품·할인 > 왼쪽 목록 아래 + 상품 한번에 추가
- 사진 유형 선택 = 포스 화면 사진 올리기 | 메뉴판 올리기
- 업로드 = 대표자 휴대폰 알림톡 확인 ※ PC에서는 이 포스에서 올리기 선택 가능
- 인식 및 등록 = 사진 업로드 > AI 인식 결과 확인 및 수정 > 등록
- 적용 조건 = 등록된 상품이 없는 매장에서 사진 인식 사용 가능 ※ 한 번에 최대 10장. 손글씨 메뉴판 가능
- 이미 등록된 상품이 있으면 = + 상품 한번에 추가 > 엑셀로 직접 등록 ※ 인터넷 연결된 PC에서 사용
- 출처 = https://guide.tossplace.com/start/product-category-setup

## 토스POS › 매출 리포트 › 매출상세 › 당근 주문 매출 확인
모델: 토스POS (2026-11-26 공식 고객지원 가이드 확인)
키워드: 당근 주문 매출 당근 연동 주문 경로 매출 비중
- 진입 = 왼쪽 위 메뉴 > 매출 리포트 > 매출상세
- 확인 = 화면 아래의 주문 경로별 매출 비중에서 당근 주문 연동 등 주문 유입 경로 구분 ※ 당근 주문이 연동된 매장에 해당. 별도의 연동 시작 버튼 경로는 공식 안내에서 확인되지 않음
- 구분 = 주문 경로별 매출 | 결제수단별 매출 | 입금처별 매출
- 출처 = https://guide.tossplace.com/operate/sales-overview

## 토스POS › 설정 › 기타설정 › 서비스 연동 › 서비스 코드로 연결
모델: 토스POS (외부 솔루션·플러그인 연동)
키워드: 외부 서비스 설치 연동 코드 플러그인 POS API 개발자센터
- 진입 = 설정 > 기타설정 > 서비스 연동 > 서비스 코드로 연결
- 설치 = 검수 완료된 서비스의 코드 입력 > 해당 서비스 연결 ※ 서비스 코드는 연동 서비스 제공업체에서 확인
- 설치 후 확인 = 기타 > 외부 서비스 설정 ※ 화면 탭 형태의 플러그인만 메뉴로 표시됨. 웹 워커 플러그인은 메뉴에 안 보일 수 있음
- 사전조건 = 서비스 개발사의 운영 배포 및 검수 필요. 해당 매장에 설치 가능한 서비스여야 함
- 출처 = https://docs.tossplace.com/faq.html

## 토스POS › 포인트·스탬프 › 메시지 직접 발송
모델: 토스POS (고객관리 기능)
키워드: 고객 문자 카카오톡 홍보메시지 알림톡 메시지 예약 AI 메시지 초안
- 진입 = 왼쪽 위 메뉴 > 포인트·스탬프 > 메시지 직접 발송
- 작성 = 기본 메시지 또는 홍보 메시지 선택 > 템플릿 선택 > 제목과 안내 내용 작성
- 대상 = 전체 고객 | 일부만
- 예약 = 발송 날짜와 시간 선택 > 발송 예약 > 발송 내역에서 검수 및 발송 결과 확인
- AI 도움 = 메시지 작성 화면에서 AI로 초안 만들기 ※ 매장 상황에 맞게 검토 후 예약
- 제한 = 예약 가능 시간 08시~19시. 검수 통과 후 발송하며 같은 템플릿을 같은 날 두 번 발송할 수 없음
- 비용 주의 = 홍보 메시지는 공식 가이드 기준 월 300건 무료, 이후 건당 33원(부가세 포함). 변경 가능하므로 발송 전 현재 요금 확인
- 출처 = https://guide.tossplace.com/operate/custom-messages

## 토스POS › 포인트·스탬프 › 고객 정보 한 번에 등록
모델: 토스POS (고객관리 기능)
키워드: 고객정보 이관 다른 포스 이전 고객 DB 업로드 포인트 스탬프 선불권
- 진입 = 왼쪽 위 메뉴 > 포인트·스탬프 > 고객 정보 한 번에 등록
- 진행 = 안내 확인 > 1:1 문의하기 > 담당자와 이관 절차 상담
- 주의 = 신청서 및 위수탁 계약서 필요. 이관은 제출 파일 기준 1회 처리되므로 기존 포스와 데이터 동기화에 주의
- 고객 확인 = 이관된 고객은 매장에서 전화번호 입력 및 동의를 완료해야 정상 조회됨
- 출처 = https://guide.tossplace.com/operate/customer-management

## 토스POS › 픽업오더 › 주문 알림·영업 일시중지
모델: 토스POS + 토스오더 픽업주문
키워드: 픽업오더 주문접수 알림음 주문 중단 예약정산 포장주문
- 알림 설정 = 왼쪽 위 메뉴 > 픽업오더 > 주문 알림 > 알림음 및 반복 횟수 설정
- 영업 설정 = 왼쪽 위 메뉴 > 픽업오더 > 설정 > 영업시간 및 주문 접수 상태 설정
- 접수 상태 = 영업 일시중지 | 비활성화 | 활성화
- 일시중지 시간 = 1시간 | 2시간 | 3시간 | 하루
- 정산 확인 = 왼쪽 위 메뉴 > 픽업오더 > 정산 내역
- 접수 주의 = 주문이 들어오고 5분 안에 접수하지 않으면 자동 취소됨
- 출처 = https://guide.tossplace.com/operate/toss-order-pickup

## 토스POS › 편의 › 서비스 연동 › 전화주문 연동(CID)
모델: 토스POS (KT 또는 LG U+ 회선)
키워드: 발신번호 표시 CID 전화주문 고객정보 착신전환 KT LGU+
- 연동 진입 = 왼쪽 위 메뉴 > 편의 > 서비스 연동 > 전화주문 연동
- 통신사 선택 = KT | LG U+
- KT 연결 = 통신사 KT 선택 > 연결 코드 변경하기에서 CP코드·솔루션 코드 확인 > KT 통화매니저 가입 및 연동 신청 > 승인 알림톡 확인
- LG U+ 연결 = 통신사 LG U+ 선택 > 인터넷전화 계정 로그인
- 연결 후 = 포스 상단 전화기 버튼과 수신 팝업에서 고객 및 주문 확인
- KT 착신 전환 = 왼쪽 위 메뉴 > 편의 > 전화주문 연동 CID > 착신 전환 설정
- 제한 = KT·LG U+ 회선만 공식 지원. KT 통화매니저 유료 가입 필요
- 출처 = https://guide.tossplace.com/operate/phone-order

## 토스POS › 당근 비즈프로필 연동 › 지원 기능 참고 (메뉴 경로 미확인)
모델: 토스POS (2026-11 기준 공개 발표 및 사장님 스토리)
키워드: 당근 연동 비즈프로필 당근 주문 당근페이 당근 광고 매장 홍보
- 확인된 기능 = 토스플레이스 공식 소개에서 토스포스와 당근 비즈프로필 연동 및 당근 지도 포장 주문 접수를 안내
