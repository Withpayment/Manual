# LENS 데이터 입력 안내

이 폴더의 md 파일을 고치면 화면에 그대로 반영됩니다. GitHub에서 파일을 열고 연필 버튼(Edit)으로 수정한 뒤 Commit 하면 1~2분 뒤 적용됩니다.

## 파일 종류
- `*-menu.md` : **메뉴얼** (메뉴 경로, 설정값, 순서)
- `*-fix.md` : **문제 해결** (증상 → 해결)
- `list.md` : 불러올 파일 목록. **새 파일을 만들면 여기에 한 줄 추가**해야 보입니다.

## 반드시 지킬 것
- 비밀번호, 사업자번호, 고객 이름·주소·전화번호는 절대 적지 마세요. 이 저장소는 누구나 볼 수 있습니다. 필요하면 `비밀번호는 별도 안내`라고만 적습니다.
- 다른 사이트의 글을 그대로 복사하지 말고, 절차만 직접 정리해서 적으세요.

## 메뉴얼 파일 만드는 법
파일 맨 위에 4줄을 적고, `##` 줄이 메뉴 경로, `-` 줄이 항목입니다.

```
# KPN · 단말기 메뉴얼
종류: 메뉴얼
VAN: KPN
장비: 단말기

## 토스 터미널 › 설정 › 오른쪽 메뉴 › 프린터
- 출력 장수 = 1장~6장 선택
- 가맹점용 영수증 = 켜기 | 끄기
- 영수증 재인쇄 = ☰ > 결제내역 > 내역 선택 > 프린터 아이콘 ※ 날짜를 먼저 선택
- 테스트 프린트
```

## 문제 해결 파일 만드는 법
`##` 줄이 증상입니다. 아래 줄은 모두 선택이고, `장비`는 꼭 적으세요.

```
# KICC 문제 해결 (EASYPOS)
종류: 문제해결
VAN: KICC
모델: EASYPOS

## 주방전표가 출력되지 않음
장비: POS
장비2: 키오스크
원인: 알면 적고 모르면 이 줄을 지우세요
키워드: 주방전표 안나옴 출력 프린터
- 1. 프린터 점검 = 프린터 셀프 테스트 실행
- 2. 포스 재부팅
- 3. 네트워크 확인 = 방화벽 해제 확인 | IP 변경 여부 확인 ※ 안드로이드 키오스크도 동일
```
- `장비` 값은 POS, 단말기, 키오스크, 테이블오더 중에서 적습니다.
- `표시: 후불·선불 공통`처럼 꼬리표를 더 붙일 수 있습니다.

## 항목 줄 쓰는 법
`- 이름 = 값 ※ 주의`

| 값에 쓰는 기호 | 화면에서 |
|---|---|
| `A > B > C` | 순서대로 누르는 단계(화살표로 이어짐) |
| `A | B | C` | 선택지(칩으로 나열) |
| 그냥 글자 | 한 줄 안내 |
| `※ 문구` | 노란 주의 문구 |

- 한 항목에 `>` 와 `|` 를 함께 쓰지 마세요. 나누어서 두 줄로 적으세요.
- 이름이나 값 안에 ` = `(앞뒤 공백 있는 등호) 또는 ` ※ `를 쓰지 마세요.
- 줄바꿈은 항목 하나를 한 줄에 적습니다.

## 잘못 썼을 때
화면 맨 위에 **"⚠ 데이터 확인 필요 N건"**이 나타나고, 눌러 보면 어느 파일 몇 번째 줄인지 알려 줍니다.

## 새 장비 타일이 필요할 때
홈 화면의 장비 사진 타일은 코드에 들어 있어서, 새 장비를 타일로 추가하려면 코드 수정이 필요합니다. 메뉴·문제 해결 내용만 추가하는 경우에는 필요 없습니다.
