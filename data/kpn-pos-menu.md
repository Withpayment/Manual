## 토스POS › 주문
- 상품 주문 = 테이블 선택 (후불형만) > 상품 선택 > (오른쪽 하단) 주문
- 주문 취소 = 테이블 선택 (후불형만) > 취소할 메뉴 선택 > (오른쪽) 주문 취소 선택 > (오른쪽 하단) 주문
- 주문 전체취소 = 테이블 선택 (후불형만) > (오른쪽 상단) 휴지통 클릭 > "주문서와 테이블을 모두 비울까요?" 팝업 > 네 선택

## 토스POS › 결제

- 결제 완료 시 (팝업) = 내역 미표시 영수증 | 내역 표시 영수증

## 토스POS › 분할결제

- 분할 방식 = 금액으로 결제 | 더치페이 | 메뉴별 결제
- 결제수단 선택 = 신용카드 | 현금 | QR결제 | 계좌이체
- 결제 완료 시 (팝업) = 내역 미표시 영수증 | 내역 표시 영수증
