# 토스POS 공식 운영 가이드 기반 상세 메뉴 트리
종류: 메뉴얼
VAN: KPN
장비: POS

## 토스POS › 매출 리포트 › 정산 날짜 기준
모델: 토스POS
키워드: 매출 기준 주문일 결제일 환불일 정산 날짜 변경
- 진입 = 왼쪽 위 메뉴 > 매출 리포트 > 설정 > 정산 날짜 기준 선택
- 선택 = 주문한 날 매출에 반영 | 결제·환불한 날 매출에 각각 반영
- 주의 = 매출 리포트, 매출달력, 인쇄 및 엑셀에도 적용됨
- 출처 = https://guide.tossplace.com/operate/sales-report-settings

## 토스POS › 매출 리포트 › 매출 마감 시간
모델: 토스POS
키워드: 새벽 영업 매출 마감 시간 자정 날짜 기준
- 진입 = 왼쪽 위 메뉴 > 매출 리포트 > 설정 > 매출 마감 시간
- 선택 = 오전 12시 | 직접 입력
- 주의 = 마감 시각 변경 전 현재 설정을 기록. 새벽 영업 매장은 실제 영업 종료보다 3시간 늦은 시각 권장
- 출처 = https://guide.tossplace.com/operate/sales-report-settings

## 토스POS › 설정 › 정보·장애 › 버전 확인
모델: 토스POS
키워드: 포스 버전 업데이트 최신버전 프로그램 정보
- 진입 = 설정 > 정보·장애 > 포스정보/소프트웨어
- 확인 = 설치된 포스 버전 확인
- 업데이트 = 최신 버전 확인 및 직접 업데이트는 윈도우·맥 포스만 지원. 업데이트 후 포스 재시작
- 출처 = https://guide.tossplace.com/operate/pos-update

## 토스POS › 설정 › 배달 앱 연결
모델: 토스POS
키워드: 배달의민족 쿠팡이츠 요기요 배달앱 계정 연결 주문
- 진입 = 왼쪽 위 메뉴 > 설정 > 배달 앱 > 배달 앱 연결
- 준비 = 해당 배달 앱 사장님 계정 아이디 및 비밀번호
- 주의 = 앱별 지원 범위 다름. 배달의민족은 주문 접수·라이더 호출 등 지원, 쿠팡이츠·요기요는 매출 연동 및 주문서 출력 지원
- 출처 = https://guide.tossplace.com/operate/connect-delivery-app

## 토스POS › 예약 홈 › 매장 예약금 설정
모델: 토스POS (예약 기능 사용 매장)
키워드: 예약금 계좌 예약금 비율 입금 마감 알림톡
- 진입 = 예약 홈 > 오른쪽 위 톱니바퀴 > 매장 예약금 설정
- 계좌 = 계좌번호 등록 > 예약금 받을 계좌 입력
- 금액 = 고정 금액 | 전체 금액의 일부
- 대상 = 전체 | 신규만
- 마감 시간 = 30분 | 1시간 | 2시간 | 1일
- 주의 = 계좌이체 결제수단이 등록되어야 예약금 계좌 자동 채움. 예약금 입금 알림톡은 계좌이체이고 예약금이 1원 이상일 때 전송
- 출처 = https://guide.tossplace.com/operate/booking-setup

## 토스POS › 토스오더 테이블주문 › QR 테이블 연동
모델: 토스POS 후불형 + 토스오더 테이블주문
키워드: 테이블오더 QR 코드 고유번호 테이블 연결
- 진입 = 왼쪽 위 메뉴 > 토스오더 테이블주문 > 설정 > 테이블 연동
- 등록 = QR 고유번호 설정 > QR 코드 추가하기 > 8자리 고유번호 입력 > 다음
- 연결 = QR 스티커 번호별 포스 테이블 선택 > 저장
- 사전 조건 = 토스오더 테이블주문 신청 및 포스 테이블 등록 완료
- 출처 = https://guide.tossplace.com/operate/table-order-settings

## 토스POS › 키오스크 › 직원 호출 버튼
모델: 토스POS + 일반/프론트 키오스크
키워드: 키오스크 직원 부르기 호출음 호출 버튼
- 진입 = 왼쪽 위 메뉴 > 키오스크 > 설정 > 키오스크에 직원 부르기 버튼 사용
- 선택 = 사용 여부 설정
- 결과 = 손님이 직원 부르기를 누르면 포스 알림과 호출음 발생
- 주의 = 접근성 모드 일반 키오스크에서는 호출 기능이 함께 설정되어 변경할 수 없는 경우 있음
- 출처 = https://guide.tossplace.com/operate/call-settings

## 토스POS › 배달 품절 › 배달의민족 지원 상태
모델: 토스POS
키워드: 배민 품절 연동 중단 배달 품절 메뉴
- 상태 = 2026-03-05부터 배달의민족 상품 품절 연동 기능 일시 중단. 현재 지원 기능으로 안내하지 말 것
- 기타 = 요기요는 배달 앱 상품 품절 기능 미지원
- 출처 = https://guide.tossplace.com/operate/delivery-settings
