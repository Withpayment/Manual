## A. 사전 준비

### A-1. 확인사항 & FirstPOS 상품 필수 설정

1. **사전 확인사항**
   * **MMS:** 계정 ID / PW
   * **ASP:** 계정 ID / PW
   * **USMS:** 계정 ID / PW (※ 대리점 당 USMS 계정 1개씩 매칭)
   * **UP오더 연동 기준:** 주문형 / 선불형 구분

2. **FirstPOS 상품 필수 설정**
   * `기초관리` → `상품등록` → **상품 및 분류 등록**
   * `기초관리` → `터치키등록` → `KIOSK` 탭 → **분류 및 상품 등록**
   * *※ UP오더 메뉴판은 FirstPOS의 `KIOSK` 터치키 구성을 기준으로 동기화됩니다.*

---

### A-2. ASP & MMS 설정

1. **ASP 계정 등록**
   * 경로: `기초` → `대리점관리` → `대리점관리`
   * 좌측 대리점 조회 후 우측 **[아임유 사용자 등록]** 영역에 USMS 계정(사용자ID, 비밀번호) 입력 및 저장
   * *※ 등록은 대리점당 최초 1회만 진행하며, 이후 생성되는 매장은 자동 연동됩니다.*

2. **MMS 매장 연동 설정**
   * 경로: `매장관리` → `매장마스터` → `매장관리`
   * 해당 매장 조회 후 **[부가정보]** 탭 클릭
   * **아임유 UP오더 연동 여부**를 `연동`으로 선택 후 저장
   * *※ ASP에 USMS 계정이 미등록된 상태에서 연동을 시도할 경우 오류 팝업이 발생합니다.*

---

### A-3. USMS 장비 추가

1. **아임유 USMS 로그인** (발급받은 대리점 계정 사용)
2. 상단 메뉴 `매장관리` 클릭 후 매장명 검색 및 선택
3. 우측 **[UP오더 장비]** 영역에서 `추가` 버튼 클릭
   * **장비타입:** `안드로이드 테이블오더` 선택
   * **대수:** 설치할 태블릿 수량 입력
   * **비밀번호:** 매장 단위로 동일하게 자동 생성됨
4. 하단 `일괄생성` 및 `저장` 클릭

---

### A-4. IMU ASP 사이드메뉴 설정 (옵션)

1. 아임유 ASP 로그인 (`UP오더 ASP` 버튼 활용 가능)
2. 좌측 메뉴 `메뉴관리` → `메뉴분류/메뉴` → `토핑설정2` 이동
3. **토핑그룹 등록 및 설정:**
   * 토핑그룹명 입력, 최소/최대 선택 수량, 필수 여부 설정 후 저장
4. **토핑상품 연결:**
   * 토핑그룹을 선택하고 하단 메뉴에서 해당 그룹에 속할 토핑(사이드) 메뉴 체크 후 `적용`
5. **메인 상품에 토핑 매핑:**
   * 상단에서 메인 메뉴 선택 → 우측 적용할 토핑그룹 체크 후 `적용`

## B. 설치

### B-1. 메인 POS IP 설정

1. **메인 POS IP 확인:** FirstPOS 상단 또는 윈도우 네트워크 설정에서 내부 IP 확인 (예: `192.168.0.22`)
2. **UP오더 ASP 설정:** `기초관리` → `스마트오더설정` → `스마트오더설정` 이동
3. **연동 정보 입력:**
   * **주문 서버 IP:** 위에서 확인한 메인 POS IP 입력
   * **메뉴판 설정:** `UP오더` 선택
   * **선불형 여부:** 
     * 주문형(후불): `미사용`
     * 선불형: `사용` (결제모드 `즉시결제` 선택)
   * **와이파이 설정:** 매장에서 태블릿이 접속할 Wi-Fi SSID 및 비밀번호 입력 후 저장

---

### B-2. 태블릿 설정 및 QR 로그인

1. **FirstPOS에서 QR 출력:**
   * `판매관리` → 좌측 상단 `UP오더` 버튼 클릭
   * `QR인쇄` 버튼 클릭 후 `와이파이 설정` 및 `로그인 QR` 출력
2. **태블릿 앱 실행 및 스캔:**
   * 태블릿에서 UP오더 앱 실행
   * **Step 1:** `[QR로 와이파이 설정하기]` 클릭 → 출력된 **와이파이 QR** 스캔
   * **Step 2:** `[QR코드로 로그인하기]` 클릭 → 출력된 **로그인 QR** 스캔
3. **테이블 지정:**
   * 로그인 완료 후 해당 태블릿을 배치할 **테이블 번호** 선택 후 저장

---

### B-3. 선불형 장치 환경설정

*(※ 선불형 매장일 경우 추가 진행)*

1. 태블릿 화면 우측 상단 또는 설정 진입 → `[장치 환경설정]` 클릭
2. **리더기 연결:** 연결할 카드 리더기 선택 후 `장치 연결` 클릭
3. **무결성 검사:** `리더기 무결성 검사` 실행 및 정상 완료 확인
4. **포스 다운로드 (가맹점 인증):**
   * `가맹점 다운로드` 탭 클릭
   * **사업자번호** 및 **제품번호** 입력 후 `포스 다운로드` 클릭
   * 다운로드 완료 후 `저장`

## C. 기능 정보

### C-1. FirstPOS 제어화면

FirstPOS `판매관리` → `UP오더` 메뉴에서 연동된 전체 태블릿의 실시간 상태 확인 및 원격 제어가 가능합니다.

* **모니터링 항목:**
  * 연결 상태 (온라인/오프라인)
  * 앱 버전 정보
  * 태블릿 배터리 잔량 (%) 및 충전 상태
  * Wi-Fi 수신 감도
* **원격 제어 기능:**
  * 전원 끄기 / 재부팅
  * 슬립 모드 전환 / 해제 (전체 및 개별 제어 가능)

---

### C-2. 관리자 로그인

태블릿 화면에서 관리자 설정 메뉴로 진입하기 위한 인증 방식입니다.

* **비밀번호 규칙:** **현재 시각 기준 `[시 + 분]` 4자리 숫자**
  * *예시: 현재 시간이 오후 2시 5분(14:05)인 경우 → `1405` 입력*
* 로그인 후 테이블 번호 변경, 메뉴판 새로고침, 앱 종료, 장치 환경설정 등의 관리 기능을 사용할 수 있습니다.

---

### C-3. 주문형 & 선불형 동작 Flow

#### 1. 주문형 (후불)
1. **고객:** 태블릿에서 메뉴 선택 후 `[주문하기]` 클릭
2. **FirstPOS:** 주문 데이터 수신 → 해당 테이블 주문 내역 자동 등록 및 주방 프린터 주문서 출력
3. **결제:** 식사 후 카운터 POS에서 일괄 결제 처리

#### 2. 선불형 (즉시결제)
1. **고객:** 태블릿에서 메뉴 선택 후 `[결제하기]` 클릭
2. **태블릿:** 연결된 카드 리더기로 신용카드/간편결제 승인 진행
3. **FirstPOS:** 결제 완료 데이터 수신 → 테이블 선결제(매출) 자동 처리 및 주방 프린터 주문서 출력

---

### C-4. 더치페이 (선불형 전용)

선불형 매장에서는 태블릿 주문 시 고객이 직접 분할 결제를 진행할 수 있습니다.

1. **메뉴나눔 (상품별 결제):** 주문한 메뉴 중 본인이 먹을 메뉴만 선택하여 개별 결제
2. **금액나눔 (임의 금액 결제):** 전체 결제 금액 중 원하는 금액을 직접 입력하여 분할 결제
3. **N분의 1 (균등 분할 결제):** 전체 금액을 인원수(N명)로 균등하게 나누어 순차적으로 결제

---

### C-5. 고객호출

태블릿 좌측/하단의 `[직원호출]` 기능을 통해 매장 내 요청사항을 POS로 전달할 수 있습니다.

* **동작 방식:** 고객이 호출 항목(예: 물, 앞접시, 수저, 직원호출 등) 선택 → FirstPOS 화면 우측 하단 알림 팝업 및 알림음 발생
* **호출 항목 커스텀:** UP오더 ASP의 스마트오더 설정 메뉴에서 매장 상황에 맞게 호출 버튼 문구 추가/수정/삭제 가능

---

## D. 비고 (참고사항)

### D-1. 품절처리

* FirstPOS에서 특정 상품을 **품절** 처리할 경우, 연동된 UP오더 태블릿 메뉴판에도 실시간으로 `[품절]` 표시가 반영되어 주문이 차단됩니다.
* 품절 해제 시에도 동일하게 즉시 반영됩니다.

---

### D-2. 이미지 처리

* 메뉴판에 노출되는 상품 이미지는 **UP오더 ASP**에서 개별 메뉴별로 업로드 및 관리합니다.
* 고해상도 이미지 권장 (권장 비율 및 용량 준수 시 메뉴판 로딩 속도 최적화)

---

### D-3. 지원되지 않는 기능

KPN FirstPOS 연동 환경에서는 아래 기능이 지원되지 않으므로 설치 및 안내 시 유의하시기 바랍니다.

1. **테이블 좌표 미동기화:** FirstPOS의 테이블 배치(좌표) 정보는 UP오더와 동기화되지 않으며, 테이블 명칭/번호 기준으로 매칭됩니다.
2. **기간할인 / 타임세일 미적용:** FirstPOS에 설정된 특정 시간대/요일별 기간할인 정책은 UP오더 메뉴 가격에 자동 적용되지 않습니다.
3. **일부 복합 프로모션 및 포인트 적립 제한:** 태블릿 선불형 결제 시 일부 제휴 포인트 및 쿠폰 할인은 카운터 POS를 통해서만 처리 가능합니다.
