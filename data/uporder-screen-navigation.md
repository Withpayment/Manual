키워드: 관리자 설정화면 진입 버튼 위치 업오더
- 시작 화면 = UP오더 주문 프로그램
- 진입 = 관리자 로그인 > UP오더 설정 화면
- 설정 화면 상단 = 버전정보
- 설정 화면 오른쪽 = 업데이트 체크 | 프로그램 재실행 | 환경설정 | 원격 프로그램 | 결제 모듈

- 참고 = 해당 메뉴 배치는 신버전 매뉴얼 v1.3의 14쪽 화면 기준
