# 토스POS · 네이버 리뷰 안내·이벤트 메뉴 트리
종류: 메뉴얼
VAN: KPN
장비: POS

## 토스POS › 네이버 리뷰 모으기 › 프론트 결제화면 노출
모델: 토스POS + 토스 프론트 (2026-11 공식 고객지원 가이드 확인)
키워드: 네이버 리뷰 영수증 리뷰 이벤트 프론트 결제 후 안내 노출
- 진입 = 포스 왼쪽 위 메뉴 > 네이버 리뷰 모으기
- 노출 설정 = 결제할 때 리뷰받기 노출 선택
- 보상 설정 = 리뷰 이벤트 보상 선택은 선택사항 ※ 보상이 있는 경우 보상 내용 입력
- 마무리 = 미리보기에서 고객용 화면 확인 > 오른쪽 위 저장
- 결과 = 프론트에서 리뷰 이벤트를 안내하고 고객에게 알림톡으로 리뷰 작성을 유도할 수 있음
- 출처 = https://guide.tossplace.com/operate/naver-review-event

## 토스POS › 네이버 리뷰 모으기 › 손님 화면에 이벤트 안 보임
모델: 토스POS + 토스 프론트 (2026-11 공식 고객지원 가이드 확인)
키워드: 네이버 리뷰 안뜸 알림톡 노출 안됨 이벤트 안보여
- 확인 = 왼쪽 위 메뉴 > 네이버 리뷰 모으기 > 결제할 때 리뷰받기 노출 선택 여부
- 재확인 = 설정 저장 > 고객용 프론트에서 노출 확인
- 해결 안 되면 = 토스플레이스 고객센터 1644-2955 또는 카카오 채널 토스플레이스로 문의
- 출처 = https://guide.tossplace.com/operate/naver-review-event

## 토스POS › 토스오더 테이블주문 › 네이버 리뷰 이벤트 노출
모델: 토스POS + 토스오더 테이블주문 (2026-11 공식 고객지원 가이드 확인)
키워드: 테이블오더 QR 네이버 영수증 리뷰 이벤트 노출
- 진입 = 포스 왼쪽 위 메뉴 > 토스오더 테이블주문 > 네이버 리뷰 이벤트
- 노출 설정 = 이벤트 노출 선택
- 내용 입력 = 이벤트 이름 > 이미지 > 이벤트 설명
- 미리보기 = 테이블주문 선택 > 손님에게 표시될 내용 확인
- 마무리 = 오른쪽 위 저장
- 구분 = 이 메뉴는 테이블주문 손님 화면용. 포스 결제·프론트의 네이버 리뷰 모으기 메뉴와 별도로 설정
- 출처 = https://guide.tossplace.com/operate/table-order-settings

## 토스POS › 네이버 리뷰 이벤트 › 실제 리뷰 작성·인증 주의
모델: 토스POS (2026-11 공식 고객지원 및 네이버 정책 확인)
키워드: 네이버 리뷰 자동 작성 등록 영수증 인증 보상 리뷰 이벤트
- 기능 범위 = 토스POS는 리뷰 작성 안내·화면 노출·알림톡 유도를 제공 ※ 손님의 네이버 리뷰를 자동 작성하거나 완료 사실을 대신 보증하는 기능으로 안내하지 말 것
- 방문 인증 = 네이버에서 영수증·결제 내역·예약·주문 등으로 방문 사실을 확인할 수 있음
- 정책 주의 = 실제 이용이 없는 허위 리뷰·비정상 영수증으로 리뷰를 작성하도록 유도하지 말 것 ※ 리뷰 노출 제한·계정 제재 가능
