# KICC · 카드단말기 모델별 확인된 안내
종류: 메뉴얼
VAN: KICC
장비: 단말기

## 이지체크 TS-132N › POS 연동 설정
모델: TS-132N
- 메뉴 진입 = 특수 > 2.부가장치 > 2.POS
- 포트 = POS 연결 포트 번호 선택 > 입력
- 통신 속도 = POS 연결 프로그램과 동일한 속도 선택
- 동작모드 = 1.단말기
- POS 결과 인쇄 = 0.예
- 단말 결과 전송 = 0.예
- 주의 = 실제 POS 포트와 통신 속도는 설치 환경에 맞춰 확인
- 원본 매뉴얼 = https://www.imupos.com/upload/kicc_TS-132N_v1.0.pdf

## 이지체크 모바일 › 이용 가이드
모델: 이지체크 모바일
- 공식 이용 가이드 = https://devkeep.kicc.co.kr/kr/manual/easycheckmobile_guide.pdf
- 이지체크 상담 = 1600-1234
- 주의 = 모바일 리더기 안내를 유선 카드단말기에 그대로 적용하지 않기
