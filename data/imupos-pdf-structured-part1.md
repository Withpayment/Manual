# IMUPOS 통합매뉴얼 v1.0 · PDF 본문 구조화 1차 (USMS / ASP)
종류: 메뉴얼
VAN: KPN
모델: IMUPOS · UP POS · UP KIOSK

## IMUPOS USMS › 신규 매장 서비스 신청
장비: POS
키워드: USMS 서비스신청 신규매장 ASP 아이디 설치암호
- 1. 진입 = USMS에서 서비스조회 클릭
- 2. 신청 = 서비스조회 화면에서 서비스신청서 클릭
- 3. 입력 = 서비스신청서 필수 정보 입력 ※ ASP 아이디는 영문·숫자 5자리 이상
- 4. 제출 = 요청 버튼 클릭
- 주의 = 설치암호는 프로그램 인증에 사용되므로 별도 안전하게 관리
- 원본 위치 = IMUPOS 통합매뉴얼 v1.0, 4~5쪽

## IMUPOS USMS › POS 제품키 등록
장비: POS
키워드: USMS 포스 제품키 라이선스 포스타입 인증
- 1. 조회 = 서비스조회 > 가맹점 아이디 조회
- 2. 매장 선택 = 가맹점 앞 펼침 버튼 > 매장 리스트 > 포스수 설정
- 3. 장비 선택 = 제품키 없는 POS 더블클릭
- 4. 포스타입 = 포스 기본정보에서 사용할 포스타입 선택
- 5. 등록 = 제품키 입력 > 팝업에서 포스타입 확인 > 확인
- 6. 검증 = 제품키 적용 여부 확인
- 주의 = 해당 포스타입의 라이선스가 필요하며 프로그램 설치 인증 완료 후에는 제품키 입력 취소 불가
- 원본 위치 = IMUPOS 통합매뉴얼 v1.0, 6~9쪽

## IMUPOS USMS › 영수증·주방 프린터 설정
장비: POS
키워드: 프린터 영수증 주방1 주방2 시리얼 공유 서버 출력포트
- 1. 진입 = 서비스조회 > 가맹점 조회 > 매장 리스트 > 포스수 설정
- 2. 장비 선택 = 설정할 POS 선택
- 3. 출력물 선택 = 프린트정보에서 영수증·주문서·주방1·주방2 등 대상 선택
- 4. 시리얼 = 시리얼 방식이면 출력포트와 전송속도 선택
- 5. 공유 = 프린터 공유 방식이면 드라이버 설치된 장비의 컴퓨터 이름·프린터 이름 경로 입력
- 6. 서버 = 프린터서버 방식이면 프린터 연결 장비의 출력포트 및 서버 IP 입력
- 원본 위치 = IMUPOS 통합매뉴얼 v1.0, 10~11쪽

## IMUPOS › 시리얼 프린터 서버 공유
장비: POS
키워드: 시리얼 프린터서버 공유 샘플출력 포스 IP
- 1. 연결 장비 = 프린터 연결 POS의 우측 하단 트레이 아이콘 클릭
- 2. 설정 = 프린터 정보 입력 및 공유 항목 설정 후 저장
- 3. 확인 = 저장 시 샘플 출력물이 나오는지 확인
- 4. 다른 POS = 공유받는 POS에서 공유 POS의 프린터 정보 및 서버 주소 입력
- 네트워크 조건 = POS와 키오스크는 같은 공유기에 연결되어야 함
- 원본 위치 = IMUPOS 통합매뉴얼 v1.0, 12쪽

## IMUPOS › 이더넷 프린터 서버 설정
장비: 키오스크
키워드: 키오스크 프린터 이더넷 LAN 프린터 IP 샘플 출력
- 1. 장비 설정 = 각 POS 우측 하단 트레이 아이콘 클릭
- 2. 프린터 정보 = Ethernet 프린터의 IP 주소와 관련 설정 입력
- 3. 출력 확인 = 저장 후 샘플 인쇄물 출력 여부 확인
- 4. 연동 = POS·키오스크 각각에서 해당 프린터 설정 정보 선택
- 네트워크 조건 = 프린터·POS·키오스크가 같은 공유기에 연결되어야 함
- 원본 위치 = IMUPOS 통합매뉴얼 v1.0, 13쪽

## IMUPOS USMS › 영수증·주문서 출력 양식 변경

## IMUPOS USMS › POS·키오스크 매장 설치 버전 관리
장비: 키오스크
키워드: UP POS UP KIOSK 버전 업데이트 매장설치버전관리
- 1. 진입 = 매장설치버전관리 > 매장 아이디 또는 상호 조회
- 2. 제품 = UP POS / KIOSK (Win) 탭 > 버전관리
- 3. 대상 = 회사 아이디·회사명 입력 > 회사아이디체크 > 대상 매장 선택
- 4. 버전 = 즐겨찾기 > 버전 확인 > 선택
- 5. 적용 = 확인 버튼으로 업데이터 적용
- 주의 = 영업 중 업데이트 전 영향 범위와 복구 방법 확인
- 원본 위치 = IMUPOS 통합매뉴얼 v1.0, 16~17쪽

## IMUPOS ASP › 메뉴 카테고리 및 상품 등록
장비: POS
키워드: ASP 마스터관리 메뉴등록 카테고리 바코드
- 1. 진입 = ASP > 마스터관리 > 메뉴관리 > 메뉴등록
- 2. 그룹 = 카테고리 추가 > 카테고리 이름 입력
- 3. 화면 등록 = 신규 카테고리 생성 시 메뉴그룹추가 예를 선택하면 메뉴화면구성에 자동 등록
- 4. 상품 = 메뉴 입력 시 카테고리와 상품 정보 입력
- 5. 바코드 = 바코드가 있는 상품은 바코드 등록
- 원본 위치 = IMUPOS 통합매뉴얼 v1.0, 23~25쪽

## IMUPOS ASP › POS·키오스크 메뉴 화면 구성
장비: 키오스크
키워드: ASP 메뉴화면구성 메뉴위치 폰트 이미지 버튼크기
- 1. 진입 = ASP > 마스터관리 > 메뉴관리 > 메뉴화면구성
- 2. 위치 = 추가할 위치 선택 > 메뉴 오른쪽 + 버튼
- 3. 표시 = POS·키오스크의 메뉴 그룹 및 메뉴 글꼴·크기 설정
- 4. 편집 = 연필 모양 편집 버튼 > 이미지·버튼 크기·주방 설정 수정
- 원본 위치 = IMUPOS 통합매뉴얼 v1.0, 26~28쪽

## IMUPOS ASP › 토핑 선택 아이템 등록
장비: POS
키워드: 토핑 아이템관리 카테고리 가격 0원
- 1. 진입 = ASP > 마스터관리 > 메뉴관리 > 아이템관리
- 2. 분류 = 카테고리 추가 > 이름 입력
- 3. 등록 = 토핑 선택용 아이템의 카테고리 및 정보 입력
- 가격 = 토핑 선택용으로 등록할 때 가격 항목을 0원으로 입력
- 원본 위치 = IMUPOS 통합매뉴얼 v1.0, 29~32쪽

## IMUPOS ASP › 토핑설정2 템플릿과 필수 선택 수량
장비: 키오스크
키워드: 토핑설정2 템플릿 최소 최대 필수선택 자동선택
- 1. 진입 = ASP > 마스터관리 > 메뉴관리 > 아이템관리에서 아이템 준비 > 토핑설정2
- 2. 템플릿 = 토핑메뉴템플릿 추가 > 이름 입력 > 저장
- 3. 메뉴 연결 = 템플릿 설정 > 미적용 메뉴에서 대상 선택 > 이동 버튼으로 적용
- 4. 그룹 = 템플릿 아래 토핑메뉴그룹 추가 > 이름 입력 > 저장
- 5. 수량 = 그룹 최소·최대 선택 수량 설정 ※ 최소 1/최대 1은 필수 1개, 최소 0/최대 1은 선택 0~1개
- 6. 아이템 = 아이템선택 > 항목 선택 > 추가 > 추가가격 또는 자동선택 여부 설정
- 원본 위치 = IMUPOS 통합매뉴얼 v1.0, 33~39쪽
