# KICC 문제 해결 (EASYPOS)
종류: 문제해결
VAN: KICC
모델: EASYPOS

## 주방프린터 출력 시 메인메뉴 상품과 옵션(오더) 상품의 글자 크기를 다르게 하고 싶음
장비: POS
키워드: 주방프린터 글자 크기 부가상품 옵션 오더 주문서 출력 크기 주방용
- 해결 방법 = POS(메인메뉴) > 환경설정 > 출력물 > 주문서(주방용) > 부가상품 출력 크기 ※ 보통크기로 설정
- 상품 글씨 크기 = 환경설정 > 출력물 > 주문서(주방용) > 상품목록 출력 크기
- 상품 크기 선택지 = 가로세로두배(기본) | 가로세로두배확대 | 보통크기 | 세로두배확대 ※ 홀, 테이블번호, 시간 등 다른 글씨는 크기를 바꿀 수 없음
- 부가상품 크기 선택지 = 부모설정따름 | 가로두배확대 | 가로세로두배확대 | 보통크기 | 세로두배확대

## 배달의민족 같이 쓰면 영수증이 출력되지 않음
장비: POS
표시: 후불·선불 공통
원인: KICC 단말기가 리더기 겸용으로 설정되어 있음. 프린터용으로만 설정하면 출력됨
키워드: 출력 안됨 프린터 배달앱 배민 영수증
- 전제조건 = POS에 리더기·싸인패드를 시리얼로 연결 ※ 싸인패드가 단말기에 연결되어 있으면 안 됨
- 방법1-① 이지체크 단말기 = 특수 > 2.부가장치 > 2.POS > POS속도설정 > 동작모드: 1.단말기 ※ POS·키오스크 같이 사용해도 된다고 함
- 방법1-② 싸인패드 = Y자 케이블로 POS에 시리얼 방식으로 직접 연결
- 방법1-③ 이지포스 프린터 = 환경설정 > 장비설정 > 프린터 > 프린터종류: 도시바 ※ 도시바로 설정하면 단말기를 나중에 리더기로 바꿔도 단말기가 반응 없음
- 방법1-④ 이지포스 싸인패드 = 환경설정 > 장비설정 > 싸인패드 > 시리얼제어(단말기 연동 X)
- 방법1-⑤ 주방프린터 배달출력 = 환경설정 > 장비설정 > 주방프린터 > 점유안함
- 방법2 = 배달 전용으로 별도 프린터 설치
- 단독 결제 = 단말기 단독 승인은 싸인패드 서명 없이 결제됨
- 포스 카드 결제가 안 될 때 = 환경설정 > 장비 > 싸인패드를 사용안함으로 설정
- 현금영수증 = 포스 결제창에서 번호 입력 가능

## 주문서에 옵션상품(오더상품)의 수량이 표기되지 않게 하고 싶음
장비: POS
키워드: 옵션 오더 수량 표기 샷추가 주문서 부가메뉴 출력 체크 해제
- 해결 방법 = POS(메인메뉴) > 환경설정 > 출력물 > 주문서(주방용) > 출력여부 > 부가메뉴 상품, 가격 출력함 체크 해제 ※ "샷추가 1"이 "샷추가"로 바뀜
- 키오스크에서 설정 = 환경설정 > 주방용주문서 > 부가상품 수량 출력여부 비활성화
- 주의 ※ 오더메뉴 한 종류를 1개 이상 주문하면 주방전표에 한 번만 출력되므로, 이 설정은 쓰지 않는 것이 좋음

## 주방전표(주방 주문서)가 출력되지 않음
장비: POS
장비2: 키오스크
키워드: 주방전표 주방프린터 출력 안됨 안나옴 주문서 체크 확인 프린터데몬
- 1. 프린터 점검 = 프린터 셀프 테스트 실행
- 2. 프린터 데몬 재실행 = 연결된 포스의 프린터 데몬(오른쪽 아래 실행 아이콘) 종료 > 프로그램 재실행
- 3. 포스 재부팅
- 4. 네트워크 확인 = 계산포스 방화벽 해제 확인 | 계산포스 IP가 바뀌었는지 확인 | 계산포스와 같은 공유기·같은 IP 대역인지 확인 ※ 안드로이드 키오스크를 쓸 때도 동일
- 5. ASP 설정 = 상품의 주방프린터 출력 설정이 체크되어 있는지 확인
- 6. 포스 환경설정 = 환경설정 > 장비 > 주방프린터 포트 확인 > 출력물 > 주문서(주방용)에서 주방프린터 사용 번호(01, 02 등) 체크 확인
- 주의 ※ ASP에서 주방프린터 번호를 삭제하지 말고 추가할 것 (삭제하면 이후 번호를 다시 설정해야 함)

## 주방전표가 늦게 출력됨
장비: POS
원인: 통신이 느리거나 포스 메모리가 부족한 경우가 많음
키워드: 주방전표 늦게 출력 느림 지연 프린터 속도 시리얼 벤더
- 방법 1 = 환경설정 > 장비 > 주방프린터 > 프린터 벤더를 SRP350으로 변경 ※ 한 사례에서 출력 시간이 4초에서 1초로 줄어듦
- 방법 2 = 환경설정 > 장비 > 주방프린터 > 시리얼 포트 속도를 57600으로 변경 (프린터 장비 설정도 동일하게)
- 참고 = 일반 매장은 보통 1초 안에 출력됨 | 프린터 신호가 서버를 거쳐 오기 때문에 통신이 불안정하면 늦어질 수 있음 ※ 프린터를 껐다 켜면 그동안 밀린 출력물은 나오지 않음

## 주방전표에서 상품명과 수량이 헷갈림
장비: POS
장비2: 키오스크
원인: 상품명이 길거나 숫자가 들어 있으면 수량으로 오해됨 (수량이 맨 위 오른쪽에 고정 출력됨)
키워드: 주방전표 상품명 수량 헷갈림 단축상품명 글자수 공백
- 해결 방법 1 = 상품명을 한글 기준 9자 이내로 줄임
- 해결 방법 2 = 상품명 글자 사이에 공백을 넣음
- 해결 방법 3 = ASP에서 단축상품명 사용 ※ 환경설정과 모든 상품에 설정해야 해서 번거로움. 단축상품명은 그대로 두고 원래 상품명에 공백을 넣는 방식도 가능
- 참고 ※ KICC 고객센터는 별도 개선 방법이 없다고 안내함 (게시글 시점 기준). 윈도우·안드로이드 공통

## 테이블 진입이 안 됨 (사용 중인 테이블 / 주문 비정상 종료)
장비: POS
원인: 주문 도중 포스가 꺼졌거나, 네트워크가 불안정해 탭(테이블 주문기)과의 동기화가 늦어지는 경우
키워드: 테이블 진입 사용중인 테이블 포스번호 중복 비정상 종료 LOCK 탭 동기화 오류
- 방법 1 = 포스 프로그램 재실행 ※ 시간이 지나 동기화되면 진입이 되기도 함
- 방법 2 = 환경설정 > 주문 > 부가기능 > (오른쪽 아래) 'LOCK 테이블 진입불가 여부' 체크 해제 > 해당 테이블에서 취소 > 다시 체크 ※ 영업마감·개점·전원 재부팅과 관계없이 LOCK을 풀어야 해결됨
- 방법 3 = 해당 탭(테이블 주문기)을 재부팅
- 방법 4 = 해당 탭에서 추가 주문 입력 ※ 호출 상품은 안 됨
- 주의 ※ LOCK 체크가 꺼져 있으면 포스와 탭에서 동시에 주문할 때 한쪽 주문이 누락될 수 있음. 테이블에 진입하지 못하면 결제도 안 되므로 카드 단말기로 결제해야 함

## 오더메뉴(오더그룹) 사용 시 자리이동·수량이 어긋남
장비: POS
키워드: 오더메뉴 오더그룹 자리이동 수량 추가가격 누락 포장 홀
- 설정 확인 = 오더메뉴 사용 시 '자리이동'을 반드시 체크 | 오더메뉴를 한 줄로 처리 | 오더메뉴 수량 일괄 처리 설정 ※ 포스가 여러 대면 포스마다 각각 설정해야 함
- 체크하지 않으면 = 수량형 오더메뉴가 1개만 이동되고 추가 가격이 누락됨
- 홀 ↔ 포장 변경 시 = 상품 2개를 선택한 뒤 홀을 포장으로 바꾸면 오더메뉴 수량이 2에서 1로 줄어듦 > 변경 후 상품 수량을 다시 2로 맞추면 오더메뉴도 2로 바뀜

## 이지포스·이지키오스크 설치 오류 (64비트 PC에서 MSXML/어셈블리 오류)
장비: POS
장비2: 키오스크
원인: 64비트 PC에서 MSXML이 정상 설치되지 않는 경우. 관리자 권한 없이 설치했거나 OS에 필요한 파일이 없거나 정품이 아닌 경우에도 생길 수 있음
키워드: 설치 오류 어셈블리 에러 MSXML 4.0 XML 파일 설치에러 관리자 권한 EasyConfig
- 진행 순서 = 모든 단계를 관리자 권한으로 진행 > 이지포스 설치 파일 실행 > 어셈블리 에러(또는 XML 파일을 찾을 수 없음)가 뜨면 설치 창에서 '마침' > 장비 재부팅 > MSXML 파서 설치 > EasyConfig(셋팅 파일) 실행 > 매장 셋팅 후 저장 > 이지포스 최초 실행 ※ 최초 실행 시 마스터 다운로드·반영이 필수
- 안 될 때 = 재부팅까지 진행한 뒤에도 오류가 나면 KICC 고객센터에 문의 ※ 설치 파일과 MSXML 파서는 ASP 자료실에서 받음

## 이지키오스크 '잘못된 인수가 발견되었습니다' 오류
장비: 키오스크
키워드: 잘못된 인수 이지키오스크 컨피그 emv 포스정보관리 KIOSK 주문확인창
- 원인 1 = ASP 대리점 기초정보관리 > 가맹점관리 > 포스정보관리에서 KIOSK 설정이 맞지 않음
- 원인 2 = 환경설정 > 주문확인창 > 결제가 '표시안함'으로 되어 있음 ※ '신용카드'로 수정
- 원인 3 = 프로그램 버전 문제 | 환경설정 오류 | 프로그램을 잘못 설치 ※ 버전부터 고객센터가 순서대로 확인해 줌
- 컨피그가 흰 창으로 뜰 때 = 기존 환경 파일(emv 파일)의 이름을 바꿔 백업 > 컨피그 실행 > emv 파일이 자동으로 새로 생성됨 ※ 초기 기본 설정 상태가 됨. 고객센터도 정확한 이유는 알 수 없다고 안내

## 포스 설치 시 인증 코드 불일치 오류
장비: POS
원인: 잘못된 버전(외식/유통)으로 내려받아 재설치한 경우
키워드: 포스 설치 인증 코드 불일치 MAC 주소 EasyPos 외식 유통 스마트오피스
- 확인 = KICC 스마트오피스 전산 > POS S/W 관리 > 해당 MAC 주소가 EasyPos(외식)으로 되어 있는지 확인
- 잘못 등록되어 있다면 = MAC 주소 삭제 > 포스에서 다시 인증 ※ EasyPos(유통)으로 등록된 경우

## 포스 종료 시 '누락된 Windows 구성 요소' 오류창
장비: POS
원인: 포스 프로그램이 아니라 윈도우 OS에 필요한 파일이 빠져 있는 경우
키워드: 포스 종료 오류창 윈도우 구성요소 누락 flash.ocx
- 해결 사례 = KICC 고객센터에 요청해서 flash.ocx 파일을 넣음 ※ 두 번째 종료부터 오류창이 뜨던 사례 (하나시스 듀얼, 윈도우7)

## 쿠팡이츠 화면 오류 (터치 안 됨 / 화면이 안 뜸)
장비: POS
키워드: 쿠팡이츠 오류 터치 안됨 화면 안뜸 보안프로그램 하드 공간
- 증상 1: 쿠팡이츠에서만 터치가 안 됨 = 마우스로 사용 | 쿠팡이츠 프로그램만 종료 후 재실행 또는 재설치 ※ 재설치하면 설정값이 초기화되니 주의. 쿠팡이츠 쪽에서 이지포스·일부 보안 프로그램과 문제가 있어 개선 중이라고 안내함(게시글 시점)
- 증상 2: 실행은 되는데 화면이 안 뜸 = 하드 여유 공간을 3GB에서 7GB로 늘림 ※ 한 사례의 조치 (배민은 정상이던 경우)

## 마감 시 영수증 프린터 오픈 오류 (용지가 나오지 않음)
장비: POS
키워드: 프린터 오픈 오류 마감 용지 출력 안됨 재인쇄 COM1 영수증 프린터 포트
- 조치 순서 = 포스 프로그램 종료 > cmd 실행 > dir 명령으로 com1(영수증 프린터 포트) 확인 > 프로그램 실행
- 안 될 때 = 포스 재부팅 | ASP 프로그램 업데이트 | 포트 변경
- 사례 ※ 윈도우 포스, TS-114 영수증 프린터, 마감 용지 3장 출력 설정에서 마감 시 용지가 나오지 않고 재인쇄도 안 되던 경우

## 서명패드(싸인패드) 결제창이 늦게 뜸
장비: POS
