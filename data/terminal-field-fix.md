# KPN · KICC · KIS 카드단말기 현장 장애 대응
종류: 문제해결
장비: 단말기

## 카드단말기에 통신장애 또는 IP 획득 실패가 표시됨
VAN: KPN
장비: 단말기
모델: 유선 LAN 연결 모델 공통 점검
표시: 일반 점검 · 모델별 메뉴 경로 미확인
원인: LAN 연결·공유기·인터넷 회선·통신 방식 설정 문제 가능
키워드: 통신불량 통신오류 IP획득실패 인터넷 안됨 승인불가 네트워크
- 1. 연결 확인 = 단말기와 공유기 LAN 케이블 체결 상태 확인
- 2. 인터넷 확인 = 같은 공유기에 연결된 다른 장치의 인터넷 접속 확인
- 3. 재시작 = 공유기 정상 동작 확인 후 단말기 재시작
- 4. 연결 방식 확인 = LAN 사용 단말기는 실제 통신 방식이 LAN인지 확인 ※ 메뉴 경로는 모델마다 다름
- 5. 계속 실패 = 다른 정상 LAN 케이블로 시험 후 설치 대리점에 문의
- 참고 자료 = https://sinsinmnc.com/faq?page=1 ※ 범용 현장 점검 가이드이며 KPN 공식 오류 코드 설명은 아님

## 무선 카드단말기에 네트워크 연결 실패가 표시됨
VAN: KPN
장비: 단말기
모델: KPN-6205 및 기타 무선 단말기 · LTE/Wi-Fi 방식 구분
표시: 일반 점검 · KPN-6205 시작 가이드 참고
원인: 와이파이 연결 끊김 또는 LTE 신호·개통 상태 문제 가능
키워드: 무선 통신장애 LTE 와이파이 wifi 연결실패
- 1. 통신 방식 확인 = LTE 개통형인지 Wi-Fi 사용형인지 확인
- 2. Wi-Fi 모델 = 화면 상단 아래로 내리기 > Wi-Fi 아이콘 > 연결할 네트워크 선택
- 3. LTE 모델 = 이동통신 신호 상태 확인 ※ LTE 개통형은 Wi-Fi 설정이 필수 아님
- 4. 재시작 = 단말기 전원 재시작 후 승인 상태 확인 ※ 중복 결제 방지를 위해 거래내역 먼저 확인
- 5. 계속 실패 = 개통·회선 상태를 설치 대리점에 문의
- 공식 자료 = https://cashnotepay.oopy.io/ee373215-b409-4629-938e-5718567a2015

## KIS-3210 카드 인식 실패
VAN: KIS
장비: 단말기
모델: KIS-3210
표시: 제조사 설명서 장애 조치
원인: 카드 삽입 방향·접촉 불량·리더 오염 또는 카드 문제 가능
키워드: 카드 안읽힘 IC 카드인식 실패 카드읽기
- 1. 카드 확인 = 카드 방향을 확인하고 다시 삽입
- 2. 다른 카드 확인 = 카드 자체 문제인지 구분
- 3. 반복 발생 = 카드 리더 손상 가능성이 있으므로 A/S 요청 ※ 내부 분해 금지
- 공식 설명서 = https://www.kisvan.co.kr/product-data/KIS-3210.pdf

## KIS-3210 통신 장애 반복
VAN: KIS
장비: 단말기
모델: KIS-3210
표시: 제조사 설명서 장애 조치
원인: 통신 장치 또는 연결 상태 문제 가능
키워드: KIS 통신장애 승인실패 네트워크
- 1. 거래 확인 = 승인 결과가 불명확하면 중복 승인 여부부터 확인
- 2. 연결 확인 = LAN·전화선 등 사용 중인 통신 회선의 물리적 연결 확인
- 3. 재시작 = 단말기 재부팅 후 상태 확인
- 4. 반복 장애 = KIS A/S 문의 ※ 단말기 초기화나 통신 서버 주소 임의 변경 금지
- 공식 설명서 = https://www.kisvan.co.kr/product-data/KIS-3210.pdf
