# 토스포스 공식 가이드 확인 메뉴 경로 보강
종류: 메뉴얼
VAN: KPN
장비: POS

## 토스POS › 프론트·프린터 연결 › 터미널 프린터 등록
모델: 토스POS + 토스 터미널
키워드: 터미널 프린터 IP 등록 테스트 출력 연결
- 포스 진입 = 왼쪽 위 메뉴 > 프론트·프린터 연결 > 프린터 추가하기
- 연결 유형 = 프린터 이름 입력 > 토스 터미널 무선으로 연결 선택
- 터미널에서 IP 확인 = 터미널 왼쪽 위 메뉴 > 설정 > 프린터 > 포스에 연결해 프린터로 사용하기
- 포스 등록 완료 = 터미널에 표시된 IP 주소 입력 > 테스트 출력 > 저장
- 연결 실패 점검 = 포스와 터미널이 같은 네트워크에 연결됐는지 확인
- 출처 = https://guide.tossplace.com/install/add-terminal

## 토스POS › 설정 › 프린터 연결 › 배달 주문서 출력
모델: 토스POS
키워드: 배달 주문서 출력 매수 프린터 배민 쿠팡이츠
- 진입 = 왼쪽 위 메뉴 > 설정 > 프린터 연결 > 배달 주문서 출력할 프린터 선택
- 설정 = 배달 주문서 출력 > 플랫폼별 출력 매수 지정 > 저장
- 포스별 출력 = 프린터 상세 화면 > 이 포스의 주문건만 출력할게요 선택 ※ 여러 포스 중 해당 포스 주문만 출력할 때
- 확인 = 매수가 0이면 출력되지 않음
- 출처 = https://guide.tossplace.com/operate/delivery-settings

## 토스POS › 설정 › 영수증 › 고급 설정 › 매장 로고·문구
모델: 토스POS + 토스 프론트
키워드: 영수증 로고 상단 문구 하단 문구 와이파이 비밀번호
- 진입 = 설정 > 영수증 > 종이 영수증 > 고급 설정
- 로고 등록 = 매장 로고 > 이미지 추가 ※ 가로 420px, 1MB 이하 JPG 또는 PNG
- 문구 입력 = 상단 문구 및 하단 문구 입력
- 출력 확인 = 테스트출력 > 저장 ※ 프론트 경유 시 통신 속도 9600 유지. 직접 연결은 프린터와 포스 설정 일치 확인
- 출처 = https://guide.tossplace.com/operate/printer-receipt-orders
