# KICC · POS 메뉴얼 (상품·재고·마감·판매화면)
종류: 메뉴얼
VAN: KICC
장비: POS

## EASYPOS › 상품·ASP
- 변경한 상품 반영 (키오스크) = 특정 시간에 키오스크를 재부팅하면 상품을 내려받음
- 변경한 상품 반영 (포스) = 프로그램 재실행 또는 메인메뉴 > 기초 정보 수신
- 지점별 상품 관리 (본부·매장 통제) = ASP 상품관리 > 상품등록 > 통제구분을 '본부' 또는 '매장'으로 지정 ※ 모든 상품의 바코드는 하나여야 함. 지점에서 직접 등록하면 본점 상품별 매출에 안 올라오니 본점에서 등록한 뒤 통제구분을 지점으로 바꾸는 방식이 안전. 지점에서는 가격 수정만 가능하고 상품명은 수정 불가 (2024-05-14 기준)
- 판매가 일괄 변경 = 기초정보 > 상품이관 > 상품일괄 변경 > 하단에 원하는 작업 입력 > 일괄적용 > 저장 > 조회로 반영 확인
- 포스·키오스크 터치키를 다르게 설정 (각각 진열) = ASP 기초정보 > 가맹점관리 > 포스정보관리에서 KIOSK 선택 > ASP 기초정보관리 > 터치키관리 > 터치키상품등록에서 POS, KIOSK 각각 진열 > 키오스크 환경설정 > 기능 > 터치키 마스터 사용구분을 'KIOSK마스터 사용'으로 ※ 'EasyPOS마스터 사용'으로 하면 포스와 키오스크가 같이 바뀜
- 터치키 정렬 ※ 터치키를 정렬하면 '숨김 처리한 상품' 이후부터 진열됨
- 상품 등록 이력 조회 = ASP > 기초정보 > 상품관리 > 상품등록 > 검색 > 하단 부가정보A의 세 번째 줄 '변경이력조회'
- 상품명에 특수기호 넣기 ※ 포스에서는 특수기호(예: 커피&티)가 안 되고 키오스크에서는 됨
- 상품 삭제 (단종) = ASP > 기초정보 > 상품등록 > 기본정보 > 사용구분을 '미사용'으로 ※ 매출이 발생한 상품은 삭제가 안 되고 단종 기능은 없음
- 묶음(박스) 상품 ※ 묶음·박스 기능은 없고 박스 바코드를 상품으로 따로 등록해서 사용
- 면세·과세 설정 = ASP 상품등록수정에서 해당 상품 선택 > 기본정보에서 면세 또는 과세 선택 ※ 결제에 반영되지 않으면 config에서 마스터 수신. 전산에서 거래내역과 사업자매출현황(부가세 참조)으로 확인
- 주방약어(단축상품명) 적용 = ASP 하단 기본정보의 '단축상품명' 입력 > 포스 환경설정 > 화면 > 매출등록 > 오른쪽 중간 끝 '터치키 표시 상품명'에서 기본상품명 또는 단축상품명 선택 ※ 단축상품명은 터치키에 적용됨
- 마스터 초기화 관리 (대리점용) = ASP 왼쪽 메뉴 기초정보 > 가맹점관리 > 마스터초기화관리 ※ 데이터 삭제 기능이 아니라, 서버의 데이터를 장비에서 못 받을 때 초기화해서 다시 받는 기능. 상단 '등록여부'에서 미등록을 선택해 조회했을 때 올라오면 안 되며, 미등록은 다시 등록해야 함
- 상품 일괄변경의 가격인하 = ASP 상품일괄변경 > 가격인하 ※ 전체 상품 또는 원하는 상품만 가격 인하 가능
- 포스 주방전표 단축상품명 (키오스크는 기능 없음) = ASP > 기초정보 > 상품등록 > 기본정보 '단축상품명' 입력 > 환경설정 > 화면 > 오른쪽 위 중간 '단축상품명' 체크 ※ 모든 상품에 단축상품명을 넣어야 함. 넣지 않으면 판매화면에 상품명이 안 뜨고, 주방용 주문서는 출력되지만 상품명이 안 나오며, 영수증·손님용 주문서에는 상품명이 나옴
- 부가정보 C 알림 메시지 = ASP > 상품등록 > 기본정보 > 부가정보C ※ 오더메뉴에 수량 제한을 두고 많이 주문되면 시간이 걸린다는 것을 알리는 용도의 메시지. 타 가맹점 요청으로 만들어진 기능
- 판매 가능한 요일·시간 설정 = ASP 부가정보B에서 판매가능 시간과 판매불가 요일 설정 ※ 판매불가 요일을 체크하면 시간과 상관없이 판매 불가. 윈도우 포스는 반영되지 않고(계속 보임), 윈도우 키오스크는 상품이 안 보이며, 안드로이드 키오스크·테이블오더는 상품이 그대로 보이고 알림창이 뜸
- 포스 화면에서 상품 등록 = 환경설정 > 매출등록 > 왼쪽 중간 '[외식매장 전용옵션] 상품등록 기능 사용함' 체크

## EASYPOS › 재고·유통
- 최초 재고 등록 / 재고 초기화 = 재고관리 > 재고조정(실사) > 단품실사 등록 > 상품조회 > 실사재고 낱개수량에 현재 재고량 입력 ※ 재고조정은 이전 재고를 무조건 덮어씀. 엑셀 업로드도 기존 재고를 무시하고 엑셀 값으로 입력됨(기존 2 + 엑셀 20이어도 22가 아니라 20)
- 이전 재고를 포함해서 입고 = 매입발주 > 발주관리 > 발주등록 > 발주확정 > 매입관리 > 거래선 입고 관리 > 매입확정 ※ 발주 없이 넣을 때는 '거래선 무발주 일괄등록' 또는 '거래선 무발주입고관리'를 사용
- 정가 상품 ※ 가격 변동 안 됨, 수량이 올라감
- 비정가 상품 ※ 같은 바코드도 새 줄로 주문되고 가격 변경 가능(상품명은 수정 불가, 시가로 보면 됨)
- 비정가 상품 가격 바꾸기 = 포스 판매화면에서 상품 선택 > 입력칸에 금액 입력 > 금액변경 버튼 ※ 변경한 가격은 저장되지 않음
- 가격무 상품 ※ 터치키로 쓰면 가격이 숨겨짐
- 발주 관련 메뉴 구분 (참고) ※ 매입발주는 본사가 확인용으로 쓰는 메뉴로 프랜차이즈에서는 거의 안 씀. 수주관리는 본사만, 주문입고는 프랜차이즈 지점만 사용(입고와 재고가 함께 처리되며 메뉴 요청 필요). 단독 매장 입고는 '거래선 무발주'로 처리. 자동발주(적정재고 미달 시)가 안 될 때도 이 구분을 먼저 확인. 휴대폰 앱에서 상품 등록(카메라 스캔)과 무발주 입고 등록도 가능(2024-07-10 기준)
- 입고 (거래선 무발주) = 거래선 등록(기본 1개 필수) > 거래선 상품정보 > 저장 > 거래선무발주입고관리에서 입고수량 입력 ※ 거래선은 거래처(A물류, B물류)를 뜻함. '거래선무발주일괄등록'은 엑셀로 일괄 입고되며 기존 수량에 더해짐(기존 10개 + 일괄 5개 = 15개)
- 매출거래선 (도매·특정 업체용) ※ 필수가 아님. 등록 후 판매화면에 '거래처' 메뉴를 만들어 거래처를 선택하면 가격이 달라짐. 메뉴 기본정보설정의 '세트메뉴'는 재고관리가 안 됨
- 재고 파악 = 재고관리 > 재고현황 > 월수불·일수불현황 ※ 재고현황은 매출이 있는 상품만 보이고 월수불·일수불현황에서는 등록된 모든 상품이 보임. 재고실사(현재 매장 수량)를 등록하면 기존 수량은 없어지고 등록한 수량만 남음(기존 12개에 실사 10개 → 10개)
- 유통 라벨프린터 사용 = SRP-770II 드라이버 설치 > 초기화면 > 부가기능 > 바코드출력 > 상품 대중소 선택 > 전체 상품 중 원하는 품목의 '바코드'란 선택 > 출력 ※ SLP-D220(노란색 프라이스텍)은 안 됨
- 라벨 설정 - 매대 프라이스 택 = 인쇄설정 > 바코드상품명위치변경 체크 > 크기 40x23 > 기종 SRP-770II > 커스텀 기본값 > 저장 ※ 원문 크기 표기(4023)를 40x23으로 읽음. 확인 필요
- 라벨 설정 - 상품 프라이스 라벨 = 바코드인쇄 > 인쇄설정 > 바코드상품명위치변경 체크 > 크기 40x23 > 기종 SRP-770II > 커스텀(바코드 위치 Y축 등)
- 거래선 무발주 일괄등록 (엑셀) = 환경설정 > 매입관리 > 거래선무발주일괄등록 > 엑셀 등록 ※ 소스점(작은 삼각형)이 뜨면 엑셀에서 오류 무시 후 텍스트 형식으로 저장(또는 바코드·숫자 앞에 작은따옴표를 넣어 셀에 녹색 표시). 원가는 상품등록에서 반영되지 않고 입고에서만 반영됨
- 유통기한 지난 상품 폐기 = 재고관리 > 재고조정(폐기) > 폐기등록 > 폐기확정 > 조회 ※ 재고에서 차감됨. 참고: 재고현황>현재고조회는 판매된 상품만 조회되고, 매입발주>발주관리는 재고와 상관없음
- 시가(싯가) 상품 - ASP 설정 = ASP > 상품등록 > 비정가 상품 등록(판매가 0원)
- 시가(싯가) 상품 - 포스 설정 = 포스 환경설정 > 매출등록 > 오른쪽 하단 '자동잡화등록 사용함' 체크 > 상품코드 입력(예: 000001) ※ 프로그램을 재실행하면 체크가 풀려서 안 될 때는 다시 체크해야 함(추후 보완 예정이라고 함)
- 시가(싯가) 상품 - 사용 방법 = 판매화면 숫자입력칸(상품조회 앞쪽)에 1000 입력 > enter > 등록된 비정가 상품이 뜸 > 2000 입력 > 금액변경
- 저울에서 용기 무게 설정 = 저울에 용기 올리기 > '용기' 버튼 ※ 저울 LED 화면에는 중량만 표시되고 가격은 표시되지 않음(안드로이드는 표시됨). 저울을 껐다 켜면 0으로 돌아감
- 상품이 1개일 때 용기 비용 차감 = 포스 환경설정 > 장비 > 스캐너 > 하단 '용기비용' 설정 ※ 영수증에 '용기금액 차감 5,000원'처럼 표기됨

## EASYPOS › 마감·매출
- 마감을 여러 포스에서 했을 때 전체 출력 = 환경설정 > 출력물 > 정산지 > 타포스번호 정산지 출력 체크 > 메인메뉴 > 마감정산 > 오른쪽 '포스별 매출 조회' > 전체포스
- 영업준비금 수정 = 메인화면 '영업준비금'에서 수정 ※ 처음 준비금은 개점 시 사원 선택 화면의 '준비금' 등록창에서 입력. 영업준비는 하루에 여러 번 가능하고 마감에는 합산되어 보임
- 마감별 정산 확인 = ASP > 영업속보 > 영업속보 > 당일정산내역 ※ 영업일자는 개점 시 달력 아이콘으로 수정 가능. 마감 해제는 안 됨
- 마감 후 시스템 종료 여부 = 환경설정 > 특이사항 > 일마감시 시스템종료 체크 ※ 마감정산 후 프로그램이 자동으로 꺼지며 꺼지지 않게 하는 설정은 없음. 마감정산에 시재금액을 넣으면 저장됨(2025-01-21 기준)
- 수시(중간) 입출금 등록 방법 1 = 이지포스 메인 > 부가기능 > 수시입출금계정등록
- 수시(중간) 입출금 등록 방법 2 = ASP > 입출금관리 > 입출금관리 > 입출금코드관리에서 등록 > 이지포스 메인에서 수시입출금 사용
- 개점 시 고정 영업준비금 = 포스 환경설정 > 매출등록 > 개점시 고정 준비금을 '사용함'으로 하고 금액 입력 ※ 개점 시 최초 1회 적용
- 영업·마감 시간 확인 (ASP) = ASP > 영업속보 > 당일정산내역 오른쪽 중간(개점일시, 정산일시)
- 카드단말기 단독 결제 확인 (ASP) = ASP > 승인관리 > 신용카드 > 일자별승인현황 ※ 단말기 단독 결제도 보이려면 단말기번호가 ASP에 등록되어 있어야 하고 승인관리 메뉴에서만 확인됨. 임의등록은 ASP>영업속보>신용카드매출내역에서 승인구분 'CAT'(공동망)으로 올라오고, 카드 결제 건을 '임의반품'하면 공동망이 아니라 카드사명으로 표시됨
- 포스·키오스크를 같이 쓸 때 마감 출력 설정 1 (윈도우 포스 + 안드로이드 키오스크) = 환경설정 > 출력물 > 정산지 > 타포스번호 정산지 출력 체크 ※ 총 포스 대수는 입력하지 않음. 포스에서 포스와 키오스크를 각각 개점·마감하고(키오스크는 마감과 동시에 개점 처리) 이 기능은 2023-12-12 버전(4.3.11.1015)부터이며 영업 담당자를 통해 요청해야 함

## EASYPOS › 사원·담당자
- 사원 등록 = ASP > 기초정보관리 > 사원관리 ※ 아이디는 숫자만으로 만들 수 없고, 대리점에 등록된 전체 가맹점 아이디 기준으로 중복 검사됨

- 교대 근무 설정 1 (대리점 ASP) = 대리점 ASP > 가맹점조회 > 설정 > 중간정산 ※ 마감 시 등록된 사원이 올라옴
- 교대 근무 설정 2 (가맹점 ASP) = 가맹점 ASP > 사원등록(권한: 모든 기능 사용 가능) ※ 로그인은 대리점 또는 가맹점 패스워드
- 교대 근무 설정 3 (포스) = 포스 환경설정 > 매출등록 > 개점시 고정 준비금 > 사용함(중간마감마다) ※ 마감 후 다른 직원이 개점하면 준비금란에 이전 직원의 현금 매출이 자동으로 등록됨. 전체 마감은 시재란에 전체 현금을 입력
- 교대 근무 진행 (오전·오후) = 영업등록 > 오전 사원 선택 후 영업시작 > 마감 시 '마감' 버튼 > 오후 사원 선택창에서 이어서 진행 > 마감 시 '전체마감' 선택 후 '마감' 버튼 ※ 영업준비금은 따로 입력할 수 있고 전체마감 때 영수증이 2장 출력됨. 원문 일부만 반영
- 주문 시 직원(담당자) 선택 = ASP에 사원 등록 > 포스 환경설정 > 주문 > 하단의 '주문시 주문정보 체크 여부: 체크함', '주문정보 필수 입력 여부: 필수 입력함', '주문시마다 담당자 선택(필수입력함 옵션 연동)' ※ '주문' 버튼을 누르면 선택 창이 뜨고 주방용 주문서에 주문자명이 출력됨. ASP에서 확인하려면 '포스 주문이력 조회'의 ASP 전송 설정을 추가로 해야 함
- 환경설정 비밀번호 사용 안 함 = 환경설정 > 기본 > 가운데 위치 '기능권한여부'를 '일부 기능 확인 처리'로
