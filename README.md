# LENS — 결제 단말기·POS 통합 매뉴얼

LENS는 결제 단말기, POS, 키오스크, 테이블오더의 **메뉴 사용법과 문제 해결 절차**를 빠르게 찾기 위한 모바일 중심의 검색 페이지입니다.

## 사용자 안내

1. 첫 화면에서 장비 종류를 선택하고 필요하면 VAN사·모델을 선택합니다.
2. 검색창에 메뉴 이름 또는 증상을 입력합니다. 예: `영수증 재인쇄`, `할부`, `프린터 안 나와`.
3. **전체 문서 / 메뉴얼 / 문제해결** 필터로 결과를 좁힐 수 있습니다.
4. 항목을 누르면 메뉴 경로·설정값·문제 해결 순서를 확인합니다.
5. 상단의 **화면 링크 복사**를 누르면 현재 검색조건 또는 열어 둔 항목을 다른 사람에게 공유할 수 있습니다.

입력한 검색어와 선택한 필터는 주소에 보존됩니다. 새로고침하거나 공유한 링크로 다시 열어도 동일한 검색 및 상세 화면을 복원하도록 설계했습니다.

## 콘텐츠 관리

- `index.html`: 검색 화면, 모바일 UI, 검색 로직
- `data/list.md`: 페이지가 로드할 Markdown 파일의 목록
- `data/*-menu.md`: 장비별 메뉴 경로와 설정값
- `data/*-fix.md`: 증상별 원인과 문제 해결 단계
- `data/README.md`: 입력 규칙 및 Markdown 예시

새 파일을 추가할 때에는 **`data/list.md`에도 이름을 등록해야** 검색에 포함됩니다. 자세한 작성 규칙은 [데이터 입력 안내](data/README.md)를 참고하세요.

## 실행 및 운영

서버나 유료 검색 API 없이 정적 HTML과 Markdown 파일만 사용합니다. GitHub Pages 등 정적 웹 호스팅 환경에서 실행할 수 있으며, 브라우저에서 `index.html` 파일을 직접 여는 `file://` 방식은 데이터 파일 로딩이 제한될 수 있습니다.

자료 파일은 최초 화면 진입 시 가져오므로 인터넷 연결이 필요합니다. 검색 자체는 로딩 완료 후 브라우저에서 동작합니다.

## 변경 후 확인할 항목

- 첫 화면에서 장비 4종 선택 및 모델 선택이 되는지
- `영수증`, `할부`, `프린터 안 나와` 검색에 결과가 보이는지
- 문제해결 탭·검색 중에 전체 메뉴 목록이 나타나지 않는지
- 검색과 상세 화면에서 링크를 복사한 후 새 탭에서 복원되는지
- 휴대전화에서 키보드·검색창·상단 필터·상세 보기 사용에 문제가 없는지
